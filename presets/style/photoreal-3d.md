# 畫風預設：photoreal-3d（仿真人寫實 3D）

## 風格句

角色卡、場景卡、分鏡參考圖、首幀、影片逐字用同一句；全片固定，換場景只換光態：

```text
Photoreal 3D animation, {光態}, {色調}, natural matte skin, normal skin tones, realistic detail.
```

- 後半段固定：寫實人物皮膚的寫法（取自 MiniMax 官方 video-deconstruct skill 的用詞）。
- {光態}{色調} 照視覺聖經填，例：`soft morning daylight from a tall window on the left`、`cool grey shadows with warm skin highlights`。
- 「3D animation」這個開頭會不會讓畫面偏 CG 感還沒驗證；要實拍質感就用 live-action 預設。

## 視覺聖經的預設值

這些是 G3A 提案的起點，不是使用者沒回答時的核可值。美術方向逐案照劇本和使用者的決定定（`2-分鏡.md` §1），這份預設不是任何一案的色盤或造型。使用者可以改；要刻意空、刻意平光，就在視覺聖經寫明「刻意」。

| 欄位 | 預設 |
|---|---|
| 人物美術 | 寫實比例、真實的年齡感；看得到毛孔的自然膚質，不磨皮；妝髮貼合角色的日常（淡妝或素顏）；衣服有穿過的皺褶；配件少而具體 |
| 場景美術 | 年代、地域照劇本；家具和陳設有使用痕跡；有日常雜物，不過度整齊；背景密度中等 |
| 光 | 一個具名光源（窗、日出、燈），兩種色溫；臉一側亮、一側暗 |
| 空氣 | 一種介質（蒸汽、薄霧、灰塵），少量 |
| 陳設 | 全景看得到至少 4 件，有使用痕跡，不要像樣品屋 |
| 背景生活 | 不放路人（路人人數會漂，還沒測）；用非人的生活感：亮著的燈、晾著的衣服、冒著熱氣的水壺 |
| 縱深 | 需要建立縱深、空間層次或遮擋時，優先用一個自然存在的前景元素；不為了電影感每鏡硬加 |
| 字 | 遠景失焦、背對鏡頭，或不出現 |
| 攝影傾向 | 寫實；中等對比；細顆粒（fine film grain）；自然飽和；高光不爆、黑位留細節；預設固定鏡 |
| 材質 | 皮膚 natural matte；布料看得到織紋和皺褶；木頭有紋理和磨損；金屬、玻璃有真實的反光 |
| 要避開的 | 塑膠皮膚、過度磨皮、樣品屋、過度乾淨、動漫臉、logo、浮水印、可讀文字。正面寫法例：`natural matte skin with visible pores`、`a lived-in room with everyday clutter`、`plain unbranded surfaces` |

## 角色卡

- 每位主要角色一張 16:9 卡：3/4 主視角，加正面、側面、背面；表情組。會在畫面裡說話的角色，另加「閉嘴中性」「說話中」。表情組至少一格是平靜、沒有遮擋的頭肩，給特寫裁成參考圖（規則核心 §5.2）。
- 服裝、道具細節；寫一段外觀錨點（4–6 個看得見的特徵），之後每支提示詞照抄。
- 卡上不印任何字，名字和標示都不印。
- 換裝、弄髒、變身：用編輯模式從原卡改（實測一次就成功），不重畫。

## 場景卡

- 只畫環境：沒有人、剪影、手或臉。
- 光照視覺聖經打，陳設照清單放。
- 一張卡放多個角度：主視角、反打、側面、局部。
- 前景、中景、背景三層；標出入口、主要活動區、可以拍的機位，分鏡卡的「機位」引用這些標示。

## Style Master（風格母版）

- 一張，畫幅照收件卡：9:16 用 1088×1920，16:9 用 1920×1088；`comfy.qwen_t2i`，每張約 1–1.5 分鐘。
- 畫面：作品裡典型的一般空間一角，不是任何正式場景的完整構圖；中性的自然日光，不用夜景或某一場的特殊光態；照視覺聖經的色彩關係；看得到木頭、布料、牆面的真實使用痕跡。
- 放一位匿名的人，只露肩膀以下或側後方，臉不可辨識，穿日常衣服，用來看膚質和布料；不是任何正式角色。
- 提示詞以「風格句＋環境句＋人物句」開頭，風格句的光態寫中性的自然日光。
- 不印任何字，沒有 logo。
- 用途是美術的核可基準：之後每一批角色卡、場景卡、分鏡參考圖、首幀，核可前都和它並排比對（`2-分鏡.md` §1 G3A-3、§2、§10）。
- 把它掛進 `qwen_edit` 當參考圖直接帶風格：【未驗證】，不是製作規則；可能把母版裡的人、家具或構圖帶進新的圖，測過才用。

## 分鏡參考圖

- 規格照 `2-分鏡.md` §10：每個要進製作的鏡一張，風格句和美術段同一套；先用既有核可圖、同機位母圖裁切，再低成本合成，最後才完整重新生成。
- 只要敘事看得懂，不用做到成片畫質；不能新增故事內容。核可前和 Style Master 並排比對。
