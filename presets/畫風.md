# 畫風規範（固定；照使用者的五張基準圖定）

基準圖：使用者給的五張（角色板 ×2、咖啡廳、街道、客廳），存 `資產/風格基準/`，是所有圖的核可標準。不生 Style Master；基準圖不掛進 Qwen 參考槽（驗證：掛了會把板上的人帶進新圖）。

**一句話**：高級日常的仿真人——乾淨、明亮、精修、溫暖、有人住。不是寫實紀錄、不是電影光、不是 3D 卡通。

## 鎖定的六件事（全片不變）

1. 審美：臉好看優先——理想化但可信的東亞臉、精修柔滑皮膚、乾淨眼神光；不是粗糙寫實、不是路人紀錄感。
2. 頭髮：空氣感層次、臉周碎髮、每根髮絲清楚帶柔光澤；不是死直、不是油膩。
3. 服裝：造型系統，不是清單——造型類型 → 色盤 ≤3 ＋ 1 accent → 輪廓（上柔下直、拉長）→ 霧面天然材質 → 單品 → 配件；不用大面積純黑、制式上班族制服、亮面合成材質。
4. 光：大面積柔光、明亮高調、柔和陰影過渡；室內外都暖、都乾淨；夜景用暖實用光或柔化過的冷白實用光＋遠處暖光。
5. 色：暖中性、低飽和、低對比、顏色乾淨分明；奶油米、燕麥、木棕、柔綠、灰褐、淺藍丹寧、金色陽光，一點磚紅。
6. 空間：有人住、整理過；前中後三層都清楚；窗看得到綠或城市；陳設密但整齊；不是樣品屋、不是廢墟。

**隨場景換的只有光態**（光從哪來、什麼時段）。
