# 2 美術與資產（第 2 站）

進來的條件：`已核可/1-劇本/` 裡有 `1-劇本.md`。這一站交的東西：角色板、場景卡、道具卡、場景關係表、音色，全部做完一次交；圖排成和五張基準圖並排的對照表。畫風照 `presets/畫風.md`，這一站不討論美術方向。

## 1. 基準圖

- 使用者給的五張存 `資產/風格基準/`，是所有圖的核可標準。沒有五張就停下來跟使用者要，不自己生、不生 Style Master、不掛進參考槽。
- 每張卡核可前都和基準圖並排看：`畫風.md` 的六件事有一件不像就不過。

## 2. 先寫 spec，再列清單，一次授權

卡片不是寫提示詞，是填 spec，由母版編譯（`scripts/qwen_t2i_母版.py`、`scripts/scene_t2i_母版.py`，槽位見 `查表-圖像母版.md`）。spec 寫在專案的送件腳本 `_腳本/G2_資產.py` 裡，一個角色一個 dict、一個場景一個 dict。

**角色 spec 的順序（硬規則）**：先人物審美（年齡感、臉、髮、妝）→ 再服裝造型：造型類型 → 色盤（≤3 色系＋1 accent）→ 輪廓 → 材質 → 最後才填單品和配件。劇情描述不得直接映射成單品清單；職業不決定服裝風格（上班族 ≠ 西裝白襯衫黑褲）。`gate(spec)` 不過不送。
**場景 spec 的順序**：空間一句（這是什麼地方、什麼氣質）→ 建築與開口一句（門窗、大家具、地標，照場景關係表）→ 光態從表選 → 材質 6–10 → 色彩 5–7。`gate(spec)` 不過不送。

spec 寫完，把要生成的清單（ID、類型、幾張、估時）寫進資產表（狀態「待做」）給使用者看；沒回視為過，然後出這一站唯一的選項卡：生成授權。批內 CC 自己跑完，不每張問。

| 要做的 | 怎麼做 | 一張約 |
|---|---|---|
| 角色板 | `qwen_t2i_母版.compile("board", spec)`，1088×1920，`comfy.qwen_t2i`；每個會入鏡的角色一張 | 1 分鐘 |
| 角色裁圖 | 每張板用 PIL 裁兩態：`{ID}_body`＝第 1 排四分之三格、`{ID}_face`＝第 2 排左大圖；各登記成獨立 ID | — |
| 場景卡 | `scene_t2i_母版.compile(spec)`，1920×1088；每個場景一張；分鏡會用到反打的場景多做一張同房間反方向，兩張一起核可 | 1–2 分鐘 |
| 道具卡 | 先分級：A 敘事關鍵必做、B 連戲需要才做、C 不做。用場景母版的 FEEL＋PHOTO 固定段加一句 `{道具} alone on {檯面}, {外觀}. No text.`，1920×1088【未驗證】 | 1 分鐘 |

步數、cfg 用 `comfy.py` 的預設（25 步、cfg 1），不調（驗證：40 步沒有差別）。
換裝、弄髒、變身：`comfy.qwen_edit`，`<image1>` 是原板，一次只改一處：`<image1> is the frame to edit: keep everything except {那一處}. {改成什麼}.`

## 3. 送件與紀錄

- 送件腳本只做三件事：`gate` → `compile` → `comfy.run`；提示詞不手寫、不加句。
- 每次送件 `comfy.run` 自動把實際送出的提示詞、seed、尺寸、步數記進 `_腳本/生成紀錄.jsonl`；對照表從這個檔反查產生。
- seed 寫進資產表；沒被要求「換 seed」就用同一個。

## 4. 場景關係表（每個場景一段，五行以內）

寫在專案 `2-資產.md`，場景卡出來之後照卡上實際的方向寫（卡上窗在右，表就寫右）。分鏡卡的機位只寫編號；提示詞和鏡頭表的左右都從這張表推。

```text
SC02 貴賓休息室
門：南（攝影機背後）｜窗：東、西兩面落地窗｜大家具：長桌南北向在中央，兩側各一張皮椅
誰坐哪邊：助理西側椅、苏晚星東側椅，隔桌寬邊對坐
機位：M1 桌子南端往北，平視，3 公尺，背景北牆矮櫃｜M2 助理右後方往東，平視，2 公尺，背景東窗｜M3 苏晚星右後方往西，平視，2 公尺，背景西窗
```

## 5. 審核、核可、重做

- 交件一次交齊：對照表圖（每張卡旁邊排基準圖縮圖，程式拼的）＋資產表＋場景關係表＋音色檔清單＋待決清單。
- 交之前 CC 先自己對：六件事（`畫風.md`）；板上每格同一張臉、同一套衣服、四排都在；場景卡沒有人、沒有字（小字痕跡放大看，有就重做或取景避開）；配件、道具數量照 spec。有一項不對就自己重做，同一張同一個問題最多兩輪；交件時寫明哪幾張重做過、為什麼。
- 使用者只回有問題的項目；沒回的視為過。過的檔移進 `已核可/2-資產/`（原板、裁圖、場景卡、道具卡、音色檔、`2-資產.md`），資產表狀態改「核可」。`已核可/` 裡的東西 CC 不改、不重生、不改名。
- 重做只改被點名的那一個槽：改 spec 的那一格，seed 不動；重做前先貼舊值→新值。想加規則、換做法、覺得缺什麼：寫進工單的「待決」，交件時一起給使用者。
