# 查表：圖像母版（角色板、場景卡；寫圖像 spec 時翻，不是每站讀）

固定段的原文只有一份，在 `scripts/qwen_t2i_母版.py` 和 `scripts/scene_t2i_母版.py` 裡；這裡寫槽位、允許值、Gate 和證據。
來源：使用者 2026-10-11 給的三份分析（型錄畫風、服裝造型系統、場景五件事）＋沙盒驗證（`D:\skill-test\v2-accept\`，每次送出的提示詞和 seed 都在 `_腳本/生成紀錄.jsonl`）。

## 1. 角色板母版（`qwen_t2i_母版.compile(asset, spec)`）

固定順序：TASK → STYLE FOCUS（型錄十行）→ BEAUTY（填）→ WARDROBE（填）→ FINISH（整體感、燈光、色調修圖）→ LAYOUT（四排板／單人全身／三視圖）→ NO。
版型放最後、寫成完整結構句（驗證：放在長母版後面會被蓋掉；放最後 12/12 對）。

### BEAUTY 槽（每個都要填，不多加）

| 槽 | 允許值（例） |
|---|---|
| age | sixteen／seventeen／in her early twenties／in his early thirties／in her mid-thirties／in her late twenties |
| build | petite／slim／lean／slim and poised／slim with an elegant figure |
| face | a small round face／a small delicate oval face／a clean oval face／a refined oval face／a striking oval face |
| features | soft youthful East Asian features／refined East Asian facial features／elegant East Asian features／glamorous East Asian features |
| eyes／nose／lips | large gentle eyes、soft almond-shaped eyes、calm dark eyes／a small nose、a straight delicate nose／soft pink lips、softly defined lips、full lips |
| skin | 固定尾句 `clear fair skin with gentle beauty retouching`（skin_tone 可換） |
| hair | 長度色澤＋質感＋造型：空氣感層次、臉周碎髮；不寫死直長髮、不寫低馬尾，除非劇情要求 |
| makeup | no visible makeup／very light natural makeup／soft natural makeup／polished natural makeup／polished evening makeup，各接細節句 |

### WARDROBE 槽（先填前四格才准填單品；劇情不得直接映射成單品清單；職業 ≠ 服裝風格）

| 槽 | 規則 |
|---|---|
| archetype | 一個名字＋2–3 個形容（例 soft urban minimal, Korean-Japanese casual, understated and premium） |
| palette | main 1–3 個色系＋accent 1 個；主色不得是 black（劇情明寫才可，標 story_required） |
| silhouette | upper／lower／overall 各一句 |
| materials | ≥4 種，編譯器自動接 `all matte and natural-looking` |
| items | outer／top／bottom／shoes；連身裙用 one_piece 取代 top＋bottom |
| accessories | 1–3 件，和鞋同一個 styling language |
| forbidden | 一句：這個類型特別要擋的 |
| flat／acc | 第 3 排四件、第 4 排配件的名字（版型句用） |

醜衣 Gate（`gate(spec)`）：色盤數、輪廓三句、材質 ≥4、單品齊、配件 1–3、禁字（glossy、PU、patent、nylon、polyester、sequin、metallic fabric、shiny）、主色 black。

### 證據

| 測試 | 結果 |
|---|---|
| P1 母版原文單人 ×6 | 型錄感對（臉、髮、光、色、服裝）；Layout 段被長母版蓋掉 |
| P2 vs P2b 同 seed 只換服裝段 | 清單（灰外套黑褲）＝路人；造型系統＝型錄 → 畫風一半在服裝 |
| P3 四排板 ×3 | 3/3 版型對、每格同一人、無字 |
| P4／P5 | 背景灰階、髮絲光澤、臉部雕琢三處用字無效；25→40 步無效（收尾質感是模型傾向） |
| P6 五種類型 × 2 seed（男、少女、女學生、成熟、美艷） | 10/10 版型對、造型照 spec、同一部作品 |
| C 組 基準板掛 `<image1>` | 臉被基準板的人帶走 → 基準圖不掛進參考槽 |

## 2. 場景卡母版（`scene_t2i_母版.compile(spec)`）

固定順序：TASK → FEEL → SPACE（空間一句＋建築開口一句＋光態句）→ MATERIALS → LIVED-IN → PALETTE → LIGHTING → PHOTO → CAMERA → BLANK → NO。先寫氣氛，再寫家具。

### 槽

| 槽 | 規則 |
|---|---|
| interior／scene_type | 室內或室外；一個名詞片語（例 hospital corridor） |
| space | 一句：這是什麼地方、什麼氣質 |
| architecture | 一句：門窗開口、大家具、地標；室內要寫到窗或開口看得到什麼 |
| light＋light_via | 光態從表選：sunny_afternoon／soft_morning／overcast_after_rain／night_warm／night_cool_practical；light_via 填光從哪來 |
| light_extra | 最多加 1 項場景專屬光 |
| materials | 6–10 項 |
| palette | 5–7 項 |
| street | 街道類：人不當主體（仍不寫路人） |

醜景 Gate：材質數、色彩數、光態在表、三句都有、室內有開口、禁字（dirty、decay、abandoned、grime、rust、broken、cracked、gloomy、harsh、oil stain、faded、derelict）。

### 證據

| 測試 | 結果 |
|---|---|
| 10 場 × 2 seed（室外：民政局門口、老公寓騎樓深夜、醫院大門雨後、公園步道、住宅巷弄黃昏；室內：醫院走廊夜、貴賓休息室夜、辦證大廳日、便利商店夜、小公寓臥室早晨） | 20/20 內容照 spec、暖光精緻感一致、2 seed 穩 |
| No text／No people 擋不住小字和人 | 加 BLANK 句後：人消失 1/1、大告示空白 2/2、六張無退步；包裝與門牌仍有小字痕跡（靠審圖、取景避開） |
