# 2 分鏡：視覺聖經、資產、鏡頭表、分鏡卡、音色資產、分鏡參考圖、首幀、Animatic、Final Shot Lock（第 2 站）

關卡：G3A 美術鎖定（訪談 → 視覺聖經 → Style Master → 鎖定）→ G3B 資產 → G4A 敘事骨架（`2A-分鏡敘事.md`）→ G4B 文字分鏡（分鏡卡、鏡頭表、曲目單）→ G4C 敘事驗收 → G5A 音色資產 → G5B 分鏡參考圖與首幀（§10）→ G5C Animatic（§11）→ G5D Final Shot Lock（§12）。G3A-4、G4C、G5C 的結果記進專案這份檔最前面的關卡紀錄表（§12）：鎖定前的依據只有 `1-劇本.md`、鏡頭表和這份檔，工單不算。

## 1. 視覺聖經與美術鎖定（G3A）

美術方向是創作決策，只有使用者能鎖定。本 skill 負責分析、推薦、整理，再翻譯成提示詞。G3A 分四步：G3A-1 訪談 → G3A-2 視覺聖經 → G3A-3 Style Master → G3A-4 鎖定。

### G3A-1 美術方向訪談

1. 先讀劇本、事件表、收件卡選的畫風預設，和使用者已經提供的參考圖。
2. 用白話提出一個主方向，加 2–3 個可選方案，每個方案寫色調、光、人物、場景各一句；方案可以混搭。
3. 只問會改變畫面的決定，一次最多 4 題；收件卡或使用者已經決定的不再問。題目從這六類挑：
   - 整體視覺類型（收件卡選過畫風就不問）；
   - 整體氣質：照劇本推薦 2–3 個；
   - 人物：生活化／自然但稍精緻／時尚短劇感；劇情需要時再問妝感、髮型精緻度、服裝階層；
   - 場景：真實居住感／整潔但不是樣板間／精緻商業空間；劇情需要時再問年代、城市、經濟階層、新舊；
   - 光和色：自然中性／暖色生活感／冷色壓抑／高對比電影感；可以日夜或場景各定；
   - 明確不要什麼。
4. 使用者用自然語言回答就好，例如「不要太乾淨」「不要塑膠皮膚」。寫進視覺聖經和提示詞時，由本 skill 轉成正面描述。
5. 沒有使用者的決定，不能把畫風預設的值當成核可結果。

### G3A-2 視覺聖經（Style Bible）

把使用者確認的方向整理進下表，連同美術段先給使用者看；使用者說「鎖定」，或指出要改的地方（例：人物再生活化一點、夜景再冷一些），改到核可為止。

視覺聖經就是這部作品的 Style Bible：美術只有這一個真相來源，不另開美術文件。每一欄都要填「決定」，可以填「無，刻意」。沒人決定的地方，模型會用它的平均值補，通常就是空、平、乾淨。

| 欄位 | 寫什麼 | 誰會讀 |
|---|---|---|
| 畫風 | 收件卡選的畫風預設 | 風格句開頭 |
| 風格句 | 照畫風預設的公式填光態、色調 | 每一支圖和影片的提示詞 |
| 人物美術 | 寫實程度、年齡感、五官方向、膚質、妝髮、髮型和髮質、身材比例、服裝設計語言、配件 | 角色卡、外觀錨點 |
| 場景美術 | 年代、地域、建築、家具、新舊、整潔程度、生活痕跡、背景密度 | 場景卡 |
| 色盤 | 主色、輔色、強調色、不用的顏色；膚色；人和背景怎麼分開 | 風格句的色調、美術段 |
| 光 | 每個場景的具名光源、方向、色溫；對比；能不能用低調光；臉哪一側亮、亮到什麼程度；畫面裡看得到的燈 | 風格句的光態、分鏡卡的「光」 |
| 攝影傾向 | 只定作品級：寫實或造型化、對比、景深傾向、固定或手持、銳度、顆粒、飽和度、高光、黑位。每鏡的焦距、景別在分鏡卡定 | 分鏡卡的焦距光圈和運鏡、Style Master、分鏡參考圖和首幀的顆粒 |
| 材質 | 皮膚、布料、金屬、木材、玻璃、塑膠、牆面、地板 | 美術段 |
| 空氣 | 一種介質和份量，或「清澈，刻意」 | 風格句、分鏡參考圖、首幀 |
| 陳設 | 材質、使用痕跡；全景、中景、特寫各看得到什麼 | 場景卡、分鏡參考圖、首幀、提示詞的場景句 |
| 背景生活 | 無人／零星／熱鬧；人只放遠景，人數寫死 | 場景卡、提示詞 |
| 縱深 | 需要空間層次或遮擋關係時，用哪一種自然存在的前景；不強制每鏡都有 | 分鏡卡、分鏡參考圖、首幀 |
| 字 | 畫面裡的字怎麼處理：遠景失焦、背對，或不出現 | 卡片、分鏡參考圖、首幀、提示詞 |
| 要避開的 | 例：塑膠皮膚、過度磨皮、樣品屋、過度乾淨、動漫臉、logo、浮水印、可讀文字。寫成畫面裡應該有的樣子：Qwen 的負面欄不起作用，H3 的否定句也沒用（規則核心 §7.2） | 美術段、一致性檢查 |

預設值在畫風預設檔，只當提案的起點。

**美術段**：從人物美術、場景美術、材質、要避開的這幾欄，寫成正面的英文描述，全片固定，分兩部分：環境句、人物句，各 1–2 句。
- 圖片提示詞的開頭：畫面有人＝風格句＋環境句＋人物句；畫面沒有人（場景卡、道具卡）＝風格句＋環境句，人物句一寫進去就容易生出人來。不每張圖各寫一套美術描述。
- 光源寫成場景裡合理存在的光（窗、天光、場景裡的燈），不寫成「畫面裡看得到的窗或燈」，免得模型把光源本體塞進近景。
- H3 影片提示詞照舊只用風格句，美術段沒在 H3 驗證過。

### G3A-3 Style Master（風格母版）

視覺聖經和美術段核可後才生成候選。

- 一張圖，用來鎖光、色、膚質、材質、寫實程度、場景質感和後期質感。它是中性的美術基準：不是任何正式角色，也不是任何正式場景的完整構圖；用中性的自然光，不用夜景或某一場的特殊光態，免得掛圖時把那一場的光和配置一起帶走。規格見畫風預設檔。
- 候選一次 2–3 張，生成前要使用者授權。
- 用途是美術的核可基準：之後每一批卡片、分鏡參考圖、首幀，核可前都和 Style Master 並排比對（§2、§10 一致性檢查）。
- 把它掛進 `qwen_edit` 當參考圖、直接帶風格：【未驗證】。可能把母版裡的人、家具或構圖帶進新的圖，測過才用。

### G3A-4 美術鎖定

四項都要有：美術方向訪談完成、視覺聖經經使用者確認、美術段經使用者確認、Style Master 經使用者核可。只把表格填滿不算鎖定。鎖定前不批量生成任何視覺資產（角色卡、場景卡、道具卡、分鏡參考圖、首幀）；Style Master 的候選不在此限。鎖定後在關卡紀錄表記 `G3A｜LOCKED｜依據`（§12）。關卡選項：鎖定美術／修改指定欄位／重做 Style Master。

## 2. 資產（G3B）

- 參考圖照收件卡的來源：使用者提供的照規則核心 §5；要生成的照畫風預設檔的卡片規格。
- 資產表：每張圖一個 ID、一個態，寫明哪一鏡用哪一張（一圖一態，多態板先裁）。表頭要有「ID」「檔案」「狀態」三欄，ID 不重複，檔案寫專案裡的相對路徑，狀態只用 待做／待審／核可；分鏡卡的「素材」用 ID 引用（§4），「用在」只是從素材反查的索引，不是製作依賴的來源；G5D 只算要進製作的鏡實際引用到的資產，鎖定前每一個都要是核可（§12）。
- 要拍特寫的角色，從角色卡的表情組裁一格平靜、沒遮擋的頭肩，當特寫的角色參考圖（規則核心 §5.2），資產表登記成獨立一態。
- 道具先盤點再生成，照劇本和事件表分三級，資產表登記級別：A 敘事關鍵，必做；B 反覆出現，照連戲需要做；C 一般背景，不做獨立資產。
- 一致性檢查：每一批卡片核可前和 Style Master 並排看，有一項對不上就修，不帶到下一站。
  - 角色：同一角色各張的身份、臉、髮型、身材一致；年齡感、材質、光和色和 Style Master 是同一家族。
  - 場景：美術方向、色盤、光、材質、陳設語言、整潔程度、年代。
- 關卡選項：鎖定資產／修改指定項目。

## 3. 從事件到鏡頭（G4A → G4B）

### G4A 敘事骨架

整集先照 `2A-分鏡敘事.md` 跑完，才寫任何一鏡的完整分鏡。不要做完一鏡的攝影細節才做下一鏡，後面刪鏡、合併時才不會大量返工。

- 一個事件可以有幾個拍、幾鏡；一鏡不跨兩個事件（跨事件合併要問）。
- 每個候選鏡只寫分鏡卡的標頭（鏡號、事件編號、多懂了什麼）和 2A 那五行：拍和類型、表達點、刪除損失和更簡形式、尺度和功能、判定（2A §18）。分鏡卡最前面放敘事帳。
- 不建鏡頭表；不寫站位、景別、機位、焦距、動作卡、聲音、首幀。
- 判定的處理：
  - 保留：進 G4B。
  - 合併：留在骨架、寫明併進哪一鏡，不進 G4B，也不進鏡頭表。
  - 刪：留在骨架紀錄，不進 G4B。
  - 拆：建立新的子候選鏡，每一個重新跑 G4A；原本的父候選只留紀錄。
  - 改通道：改表達點或通道後，重新跑 G4A。
  - 問：列給使用者，附原本、建議、理由、不改的代價；沒解決前不能進 G4B。
- 使用者核可的劇情改動：先改第 1 站的 `1-劇本.md`（故事、台詞、事件表），再重新跑受影響的 G4A。不能只在分鏡卡上改核可的故事內容。
- 鏡數只算收斂後要進 G4B 的鏡：判定保留的鏡，加上拆出來而且保留的子鏡；刪和合併的紀錄、被拆掉的父候選都不算。超過收件約定時，照 `1-劇本.md` §3 第 4 條問使用者。
- 給使用者看之前自檢：每個事件都有候選鏡；一鏡不跨兩個事件；每個候選鏡都有 2A 的判定；要進 G4B 的鏡最後判定都是保留，沒有還沒處理的拆、改通道、問；延宕、停留、定向、呼應鏡的前提都成立（2A §5）。
- 關卡選項：核可敘事骨架／修改指定候選／回到第 1 站。

### G4B 文字分鏡

只展開 G4A 判定保留的鏡，在同一張卡上補完。依序決定，後面的都從前面推出來：

1. **敘事目的**：照 G4A 的標頭和拍。推進鏡寫觀眾這時多懂了什麼；延宕、停留、定向、呼應鏡寫類型和表達點（2A §5）。
2. **站位**：人在空間裡的起點、終點、路線；誰在畫面左、誰在右。
3. **鏡頭**：景別照 G4A 定的尺度和 2A §12 的雙向檢查決定；機位、焦距、光圈要能用敘事目的解釋。例如：要觀眾自己看出人和空間的關係 → 較廣、景深深；要觀眾只盯著一個人 → 較長焦、景深淺；道具在講故事 → 道具要清楚，不求散景。淺景深留給真正需要孤立人物的鏡，不要每鏡都用。
4. **動作**：照動作卡（§5）。
5. **聲音**：聲音類型、環境聲、動作聲的時間點；有心聲、旁白就排旁白窗。新增的聲音會帶出原因、資訊或觸發的，照 2A §15 問。
6. **首幀從哪裡來**：接力、借相鄰已核可的畫面、合成首幀，或不用（§10）。
7. **要不要拆段**：一次生成控制不住先後順序的，拆成 A、B 段（§5）。

- 反應只有在它本身就是主要表達點、而且目前的鏡頭內做不清楚時，才另給一鏡；景別照 Visual Scale 決定（2A §12）。
- 不拍備用角度：每鏡只生分鏡上要用的那個角度（正式檔位一條要 6–19 分鐘）。
- 卡都寫完，才建鏡頭表（§4）、跑鏡頭表檢查；給使用者看之前照 §8 自檢。

## 4. 鏡頭表與分鏡卡

**鏡頭表** `2-鏡頭表.csv`：G4B 才建。總覽、連戲、狀態都在這一張。第一列欄位：

```text
鏡號,秒數,敘事目的,畫面內容(一鏡一事),台詞(逐字),站位(誰左誰右),視線(看著什麼),手上道具,參考圖,首幀來源,狀態,重做次數,備註
```

「秒數」是成片秒數；「敘事目的」寫事件編號＋這一鏡的拍（同 §3 第 1 項），2A 自己加的鏡寫它服務的事件編號，加註「2A 加」；合併或刪掉的鏡不進鏡頭表（紀錄留在 G4A 骨架），在吸收它的鏡的「備註」寫明；「參考圖」寫這一鏡分鏡卡「素材」裡的資產 ID（總覽用的鏡像，以素材為準，鎖定前要一致，不算進指紋，§12）；「首幀來源」寫 接力 S03 末格／借 S08 第 0 格／合成／無（§10）。「狀態」只用這幾種：待生成、生成中、待審（檔名）、過（檔名、日期）、重做中（第幾次、改什麼）、回分鏡；使用者問還有哪些沒審，就從這一欄列出「待審」。寫完跑：

```text
python _腳本/檢查鏡頭表.py 2-鏡頭表.csv
```

它也照分鏡卡「生成」那一行核對：成片秒數不能超過生成幀數÷24，成片取要在生成長度裡、合計要等於秒數，台詞窗（動作卡 J）要在成片取裡；所以分鏡卡寫完再跑，❌ 修完才進 G4C。

**分鏡卡** `2-分鏡.md`：最前面放一份敘事帳（未解問題、呼應帳、景別序列，2A §18）；之後每鏡一張，鏡頭表有的欄位不重寫。G4A 只寫標頭和拍到判定那五行，G4B 在同一張卡上補完其他欄位，不另抄一份。

```text
{鏡號}｜{事件編號}：{觀眾這時多懂了什麼}
拍：{主體}：{A} → {B}｜{類型}｜推動 {一兩項}
表達點：{…}｜通道 {…}｜支持 {最多兩個}｜（要保留資訊時加）禁露 {…}
刪除損失：{…}｜更簡形式：{無／併入 Sx／前一鏡出點停留…}
尺度：{SPACE／BODY／FACE／DETAIL}｜功能：{交代／動作／說話／注意／反應／呈現}
判定：{保留／合併／刪／拆／改通道／問}｜劇情改動：{無／問題 n}
為什麼這樣拍：{景別}；寬一級：{相鄰景別，失去什麼}；近一級：{相鄰景別，增加什麼}；替代：{無／某景別，什麼條件下}；{機位、焦距光圈怎麼服務敘事目的}
生成：{模式}、{幀數}；首幀 {來源}；成片取 {a–b} 秒（拆段的鏡分 A、B 兩行，§5）
景別：{中文名}＝{英文詞}；{畫面邊界}（例：中景＝medium shot；頭頂到腰，§6）
機位：{水平角度}、{高度}、{距離}；場景卡機位 {編號}
軸線與接縫：{和上一鏡差幾級景別、差幾度}；{接縫放在哪一種不連續上：換場、換角度、時間跳躍（規則核心 §2.5）}
焦距／光圈／焦點：{mm}、f/{…}、焦點在 {誰的哪裡}；{看得見的效果}
光：{從視覺聖經繼承，這一鏡的修正}
動作卡：A–K（§5）
聲音：{類型}；{環境聲}；{動作聲＋時間點}；旁白窗 {a–b 秒}
素材：{照接入順序：首幀、資產 ID、Voice ID}（例：首幀、CHR01、SC01、V01；資產 ID 的順序＝參考圖接進 H3 的順序＝<Picture N>，Voice ID 只列這一鏡在 H3 片段裡出聲的、順序＝<Audio N>）
連戲交接：起手 {接上一鏡最後一格的八項}；收尾 {交給下一鏡的八項}
紅燈三問：兩人都在動？有身體或道具接觸？超過一個主要變化？{兩個「是」＝紅燈，寫拆或不拆的理由}
風險：{只給人看，不寫進提示詞}
```

拍到判定那五行的寫法見 `2A-分鏡敘事.md` §18；敘事目的、拍、表達點、為什麼這樣拍、風險都只給人看，不寫進提示詞。

**素材**是這一鏡要掛哪些參考圖、照什麼順序的唯一來源（送件前檢查照它比對，`4-生成與驗片.md` §1）：鏡頭表「參考圖」、資產表「用在」都從它推。Voice ID 是 §9「使用鏡頭」的鏡像：只列沒加註的（在這一鏡出聲的），心聲、旁白的音色不列；鎖定前兩邊要一致（§12）。

**連戲交接**：每個切點記一筆，八項都寫：姿勢（坐、站、翹腳）、在畫面哪裡、兩人距離、表情和情緒、服裝、手上道具、機位在哪一側、景別。下一鏡第 0 格要跟上一鏡最後一格一樣，要變就寫明為什麼。鏡頭表只追站位、視線、手上三欄，被退件的連戲問題多半出在其他幾項。

## 5. 動作卡（每一鏡都填；對白鏡的「主要變化」可以是一句台詞或一個表情變化）

```text
A 主要變化：只有一個
B 第 0 幀：每人的畫面位置、對鏡頭的角度、視線、左手、右手、腳、正在做的動作和速度；不動的也寫「不動」。只寫這個景別看得見的部分，看不見的狀態寫在連戲交接
C 觸發時間 T1：首幀距離 ÷ 真實速度；寫 ≤1 秒（實際常晚約 1 秒）
D 觸發：看得見或聽得見的起因
E 主動作＋同一瞬間的後果：誰、碰到哪裡、多快；液體或道具怎樣；被撞的人往畫面哪邊、退幾步
F 反應與平衡：每人一句（哪隻腳接住重心、手臂、頭髮外套甩出去再落回）
G 停下時間 T2＋停住句：之後只有眼睛動，或寫明還在動的是什麼
H 鏡頭：固定鏡（全景、遠景寫一個不准動的地標在畫面哪裡；中景以內寫畫面邊界）；或一個運鏡的起止景別
I 收尾狀態：用這台攝影機看到的樣子寫，抄進下一鏡的起手
J 時間預算：0–T1｜T1｜T1–T2｜T2–片尾；沒有歸屬的秒數要是 0；有台詞的鏡在這一行寫機器讀得懂的台詞窗：台詞窗 0.5–3.5 秒（拆段寫 台詞窗 B 0.3–1.3 秒），鏡頭表檢查和剪接都照它核對
K 成片取哪一段＋判片標準：生成前寫死；停留、延宕要留的秒數也寫在這裡，細剪不剪
```

- 表情寫看得見的變化（從 A 變成 B），不寫情緒詞；一鏡 2–5 個小變化（不是 2A 的拍）。悲傷、克制的戲不寫 smile，改寫嘴唇、下巴的狀態。
- 動作用正常速度的詞；不寫起手姿勢、接觸過程、中間狀態；動作進行中不寫停、慢。
- 爆發型動作用最短片長（124 幀），剪接時取段。
- 換身體朝向或換機位，靠切鏡完成。

**一鏡拆成 A、B 兩段**（一次生成控制不住先後順序時）
- 什麼時候拆：先運鏡再動作；說完、停一下、再動作；邊講對白邊運鏡。這幾種一次生成常把順序做亂、跳過停頓，或鏡頭根本不動；拆成兩段通常一次就過。
- A 段只做到停點；B 段的首幀釘 A 段的接點那一格（不一定是最後一格，挑動作停住、畫面乾淨的那格）。
- 運鏡那段不放台詞：對白進行中鏡頭常常不動，運鏡要當成那一段的主事件。
- 剪接時在接點交叉淡化 0.25 秒：剪接設定裡 A 的迄秒寫到接點再加 0.25、交叉淡化 0.25，B 從第 0 格起（`5-結案.md` §5）。
- 分鏡卡的「生成」分兩行：A 段 {模式、幀數、做到哪}；B 段 {模式、幀數、首幀＝A 第 N 格、做什麼}；成片取 {A a–b 秒＋B c–d 秒}。送件前檢查照這一行比對模式和幀數；B 段的「首幀＝A 第 N 格」一定要寫，佇列 `after` 取的就要是 A 段那一格（`4-生成與驗片.md` §1）。
- 拆段不重新計算重做次數（`4-生成與驗片.md` §4）。

## 6. 鏡頭語言

| 景別 | 畫面邊界 | 推薦的景別詞 | H3 |
|---|---|---|---|
| 大特寫 | 只有眼睛，或只有嘴 | — | 【未驗證】 |
| 特寫 | 髮際線到下巴 | extreme close-up | 草稿 3/3、正式 2/2；角色參考圖掛頭肩裁圖 |
| 近景 | 頭頂到鎖骨 | close-up | 草稿 3/3、正式 2/3（1 條偏緊，切到頭頂） |
| 中近景 | 頭頂到胸口中段 | medium close-up | 草稿 3/3、正式 2/2 |
| 中景 | 頭到腰 | medium shot | 草稿 3/3、正式 1/2（1 條偏緊成中近景） |
| 中全景 | 頭到膝蓋 | — | 【未驗證】 |
| 全景 | 頭到腳，腳下留一點地面 | full shot | 草稿 3/3、正式 2/2 |
| 遠景 | 人在空間裡很小 | extreme wide shot | 草稿 3/3、正式 1/2（1 條偏緊成全景） |

- 景別寫法見 `3-提示詞.md` §4 每級句型。H3 照的不只是景別詞：提示詞寫到的東西它都想放進畫面，所以只寫這個景別看得見的（規則核心 §7.5）。
- 中文和英文名稱不是直譯：近景＝close-up，特寫＝extreme close-up。讀外部分鏡或教材時可用下列常見縮寫對照協助理解；這不是統一標準，不同劇組的 WS／LS／MWS／MLS 邊界會漂，只按人物在畫面中的實際大小對到本表的景別：EWS＝遠景；WS／LS＝頭到腳是全景、人很小是遠景；MWS／MLS＝中全景；MS＝中景；MCU＝中近景；CU＝近景；ECU＝特寫。只供外部術語轉換，正式提示詞仍寫上表已驗證的六個英文詞，lint 也只認那六個詞。
- H3 欄＝景別照寫的條數／跑的條數。條件：單人、固定鏡、沒有首幀、9:16、124 幀（約 5 秒）、Ref2VA＋PDD 8；草稿 416×736，正式 768×1344。正式檔位偶爾差一級，5 秒內不漂；差一級先換 seed（`4-生成與驗片.md` §5）。

| 焦距（全片幅等效） | 看起來 | 常用來 |
|---|---|---|
| 24mm | 空間寬、縱深強；近拍臉會變形 | 交代人和空間的關係 |
| 35–40mm | 自然帶到環境 | 和角色在一起、不評判；兩人同框 |
| 50mm | 接近人眼 | 中性地看 |
| 85mm | 臉的比例好看，背景壓縮 | 親近、私密 |
| 135mm 以上 | 強壓縮，背景糊成色塊 | 人被處境困住；躲著拍像在監視 |

| 光圈 | 清楚的範圍 |
|---|---|
| f/1.4–2 | 只有臉或眼睛 |
| f/2.8 | 主體清楚，背景柔和但認得出來 |
| f/4 | 前後相隔一兩步的兩個人都清楚 |
| f/8 | 大部分都清楚 |

- 焦距數字不控制景別：景別靠景別詞和只寫看得見的內容。要寫焦距，就寫數字也寫看得見的效果。兩人都要清楚時不用極淺的景深；人會前後移動時收光圈或退遠（85mm f/2、人在 2 公尺，清楚的範圍只有約 7 公分）。
- 機位：預設四分之三側角、平視；不正對人臉（規則核心 §4）。
- 直式 9:16：用前後縱深調度，少用左右橫移；眼睛放在畫面上方約三分之一。
- 軸線：兩人之間的線，攝影機只在同一側；前後鏡左右不對調，要越軸就寫明。
- 視線要接：上一鏡看向畫右，下一鏡對方從畫左接住；反打用看的人的眼睛高度。
- 移動方向要接：人往畫右跑出去，下一鏡還是往右，除非有一鏡交代轉向。
- 同一個人連續兩鏡：角度差 30° 以上，或景別差兩級（或差一級再加 30°），不然看起來像跳格。
- 運鏡：預設固定鏡；要動只寫起止景別，一鏡一個運鏡；特寫不大幅環繞；收尾不推臉部特寫。

## 8. G4B 自檢與 G4C 敘事驗收

### G4B 給使用者看之前自檢

- 每一鏡只有一個主要變化。
- 紅燈三問每鏡都答了；紅燈的鏡寫了拆或不拆的理由（只提醒使用者，不擋）。
- 台詞字數照規則核心 §2.4；每鏡一個說話人（或照規則核心 §7.25 的輪替寫法）。
- 連戲：每個切點的交接八項都寫了；起手＝上一鏡收尾；左右不對調；手上道具不瞬移；軸線、視線、移動方向接得上。
- 景別理由與序列：每張卡的「為什麼這樣拍」是一行、四個標籤照 2A §12 的字面寫（「寬一級：」「近一級：」「替代：」，景別名在冒號後，標籤裡不加括號），寬、近兩句都說了對表達點的後果；卡都寫完後，把整集的尺度和景別排成一行寫進敘事帳（2A §18），看一遍：同一人相鄰兩鏡若主體、功能和構圖都接近，重看是否形成沒有敘事價值的重複或跳切（§6）；整集沒有 SPACE 的鏡，要有全集層的理由，寫在敘事帳的「全集尺度備註」；連續三鏡以上同一景別、功能又相同 → 標出來重看；核可的揭曉或反轉所在的拍，如果沒有和一般拍形成尺度差異，「為什麼這樣拍」要說明目前尺度為什麼仍是最有效的選擇，不預設一定要更近；明顯的寬近變化要能由表達點、Visual Scale 或敘事視角的改變解釋，沒有明顯的寬→近／近→寬走向本身不算問題。這是提醒重看，不是規則；標出的鏡照 2A §12 重做雙向檢查【盲測】。
- 每一鏡的首幀來源都定了；要拆段的鏡寫了 A、B 段和接點。
- 動作卡 J 沒有沒歸屬的秒數；首幀距離算得出 T1 ≤1 秒。
- 鏡頭表檢查腳本過。

關卡選項：核可文字分鏡，進 G4C／修改指定鏡頭／回到 G4A。

### G4C 敘事驗收

G4B 核可後，用 2A 的判準把整集看一遍。這一層只驗收、列問題，不重新設計。逐項檢查：

- **漏拍**：每個事件的拍都有鏡承擔（2A §4）。
- **重複**：同一件事說了兩三次；只換景別、角度或運鏡，沒有新內容；同一種情緒連演兩鏡（2A §9、§17 第 3 步）。
- **過度反應鏡**：反應不是主要表達點，卻另給一鏡（2A §12、§13）。
- **前提**：停留、延宕、定向、呼應鏡的前提還成立；延宕對得到敘事帳裡的未解問題（2A §5、§18）。
- **伏筆和回收**：PLANT 都登記在呼應帳，回收時多了新意義；未解問題有收，或寫明刻意不收（2A §7、§18）。
- **揭曉沒有提前**：要保留的資訊沒有在前面的鏡露出（2A §17 第 6 步；揭曉的位置屬第 1 站，§15）。
- **鏡數沒有膨脹**：每一鏡都說得出刪除損失（2A §3、§8）。
- **該合併或該拆**：照獨立拍檢查和刪除測試（2A §4、§8）。
- **劇情安全**：沒有靜默替換核可內容（2A §15）。
- **連戲與景別序列**：改過的鏡，前後的連戲交接、鏡頭表和敘事帳的景別序列還接得上（§4、G4B 自檢）。

輸出問題清單：鏡號、問題、建議（合併／刪／拆／改通道／問）、根據的 2A 段落、要回哪一層。動到核可內容的照 2A §15 問。

使用者決定後，照問題的種類回去修，只重做受影響的部分：
- **敘事問題**：漏拍、重複、合併、刪、拆、改通道、過度反應鏡、停留延宕定向呼應的前提、揭曉、劇情安全 → 回 G4A 修受影響的事件和候選鏡 → G4B 只重新展開受影響的鏡 → 再跑 G4C。
- **攝影和製作問題**：秒數、站位、視線、景別、機位、焦距光圈、動作卡、聲音的執行、首幀來源、連戲 → 回 G4B 修指定的鏡 → 重跑鏡頭表檢查 → 再跑 G4C。

通過時在關卡紀錄表記 `G4C｜PASS｜依據`（§12）。關卡選項：敘事驗收通過，進 G5A／修改指定問題／回到 G4A。已通過的分鏡要改時，一樣照上面分流，只改受影響的鏡和它前後的連戲。

## 9. 音色資產（G5A）

G4C 通過後才做：到這時才確定誰真的保留台詞、誰是畫外聲、有沒有心聲和旁白。音色資產只決定「已核可的說話者用什麼聲音」，不決定誰說、說什麼。

**要出聲的身份**：從核可的分鏡卡整理一份清單——對白、畫外人聲、心聲、旁白各是誰。只替清單上的身份做音色資產；沒有聲音內容的角色不做。

**音色從哪裡來**，照這個順序：
1. 使用者提供的核可聲音參考。
2. 系列既有的核可音色：系列狀態（設定的 `series_state`）記了這個角色的音色，就直接沿用，只記引用、不另存一份。要換聲音，要使用者核可。
3. 新角色：寫聲音簡報（性別、年齡、口音、音色、能量、像誰），用 `comfy.h3_voice` 生 2–3 條候選（生成前要授權），使用者挑一條，剪到只剩說話的部分（3–10 秒，沒有別人的聲音和大的動作聲）。

音訊檔放 `資產\`，檔名 `音色_{身份}.wav`。

**音色資產表**：登記在這一段，不另開文件。

| 欄位 | 寫什麼 | 誰會讀 |
|---|---|---|
| Voice ID | 例：V01；不重複 | 分鏡卡的素材、送件、Animatic |
| 身份 | 角色名，或「旁白」 | G5A 鎖定（對得上清單） |
| 來源 | 使用者提供／系列沿用／`h3_voice` 候選第幾條 | G5A 鎖定、追溯 |
| 核可檔 | `資產\音色_….wav`，或系列狀態裡那個核可檔的路徑；要是找得到的檔案 | `h3_ref` 的音色參考（`<Audio N>`）、`h3_vo`、Animatic |
| 聲音描述 | 性別、年齡、音色 | 提示詞的聲音鎖 |
| 語速 | 慢／一般／快 | 沒有預覽語音前估台詞長度（Animatic 以預覽語音的實際長度為準，§11）；剪接要不要加速（`5-結案.md` §3） |
| 口音／語言 | 例：標準普通話 | 提示詞的聲音鎖 |
| 基準能量 | 例：輕、平穩 | 說話句語氣的起點 |
| 核可用途 | 對白／畫外人聲／心聲／旁白，只記核可劇本已經有的 | G5A 鎖定（和劇本一致）、`5-結案.md` §2 |
| 使用鏡頭 | 從分鏡卡的台詞、聲音欄整理，以分鏡卡為準；逐一列鏡號，不寫範圍。`S05`＝在這一鏡的 H3 片段裡出聲（對白、畫外人聲），送件時要掛；`S05（心聲）`、`S05（旁白）`＝只在後製和 Animatic 用，不掛 H3；同一鏡又說話又有心聲寫 `S05、S05（心聲）`。加註要和核可用途一致（加註心聲的，核可用途要有心聲；加註旁白的要有旁白；沒加註的要有對白或畫外人聲），其他加註不認 | G5A 鎖定、送件前檢查（H3 片段要掛哪幾份音色）、Animatic |
| 系列沿用 | 是／否；是的話寫系列狀態裡的引用 | G5A 鎖定、結案時更新系列狀態 |
| 狀態 | 候選中／核可 | G5A 鎖定 |

**劇情安全**：G5A 不能換說話者、改台詞、把角色台詞變旁白或反過來、新增畫外人聲或心聲、改聲音承載的事件或資訊。這些照 2A §15 問，使用者核可後先改 `1-劇本.md`。「核可用途」只記核可劇本已經有的用途，不是新增用途的權限。

**交接**
- G5C Animatic 讀 Voice ID、核可檔、使用鏡頭、核可用途，不自己另選聲音。
- 第 3 站只從核可的音色資產取音色參考和聲音鎖，提示詞不自己產生新的音色設定。
- 心聲、旁白（`5-結案.md` §2）用同一個核可檔。

**G5A 鎖定**，全部要有：
- 清單上每個出聲身份都有 Voice ID；
- Voice ID 不重複；每個 Voice ID 有核可來源，和唯一的核可檔或有效的系列狀態引用；
- 使用鏡頭追得到分鏡卡；
- 用途和核可劇本一致；使用鏡頭的加註和用途一致；
- 回歸角色沿用既有音色，或換聲音有使用者核可；
- 沒有還在候選中的音色。

通過才進 G5B；沒有通過，也不能進 G5C Animatic。關卡選項：鎖定音色資產，進 G5B／修改指定音色。

## 10. 分鏡參考圖與首幀（G5B）

G5A 通過後做。先分清楚兩件事：

- **分鏡參考圖**：預覽用的資產。每個要進製作的鏡一張，給使用者檢查構圖、敘事和美術一致性，也是 G5C Animatic 的畫面；不一定送進 H3。
- **首幀**：H3 正式生成的條件資產。分鏡參考圖要通過首幀資格，才能兼任首幀。

### 分鏡參考圖

- 每個 G4C 通過、要進製作的鏡，進 G5C 前都要有一張，對應唯一的鏡號，放 `2-分鏡圖\{鏡號}.png`。
- 從這幾樣編出來：視覺聖經（風格句＋美術段，§1）、核可的角色卡、場景卡、需要的道具卡，加上 G4B 的分鏡卡。圖不能新增事件、拍、人物、道具動作、資訊、揭曉或情緒轉折；做不到就回報、回 G4B，不改核可內容去遷就圖。
- 畫這一鏡最能讓人看懂敘事功能的那一刻（通常是表達點）；不要把整段動作的幾個時間點塞進同一張。
- 成本照這個順序，夠用就停：
  1. 既有的核可圖直接用；
  2. 同場景、同機位的母圖裁切或重新取景；
  3. 用既有資產低成本合成；
  4. 最後才完整重新生成。

  分鏡參考圖只要敘事看得懂，不用做到成片畫質。多參考圖合成的時間見 `4-生成與驗片.md` §2 的算圖時間表（約等於正式 H3 124 幀的七成），不能每鏡都這樣做。
- 生成前照授權規則：一批寫明哪幾鏡、用哪種方法、預估時間。
- 合成的提示詞：風格句＋美術段開頭，一句一件事——景別與機位；每人的位置、手、視線；光從哪來、臉哪側亮；需要時才寫前景物；陳設；遠景有什麼（失焦）；顆粒（照攝影傾向）。不寫「畫面乾淨」「空無一人」這類結尾句，除非視覺聖經寫明刻意。
- Qwen 合成的景別常比寫的寬一級；兩人的前後深度難控制；小道具細節常被忽略。改圖用編輯模式，一次只改一處。

### 首幀

- **首幀策略**：G4B 在鏡頭表「首幀來源」定好，照這個順序選：
  1. 接力：同一場連續的鏡，上一鏡的最後一格（或指定的一格），用佇列的 `after` 自動接。鏡頭表「首幀來源」寫 `接力 S03 末格` 或 `接力 S03 第 N 格`（來源鏡有拆段時加段：`接力 S03 B 段末格`；沒加，末格算 B 段、第 N 格算 A 段）；送件前檢查核對 after 接的就是這一鏡（段）、這一格（`4-生成與驗片.md` §1）。座位、距離、服裝最不會跑；但上一條結尾壞了，下一條開頭跟著壞，所以佇列會先檢查來源片，人也要看過那一格乾不乾淨。
  2. 借相鄰已核可的畫面：換角度、換場的鏡不能接力，從已核可的片段裡挑一格看得到需要的站位和座位的（例：一個看得到兩人座位的雙人畫面）。鏡頭表寫 `借 S08 第 0 格`，一樣用佇列的 `after`，送件前照樣核對來源鏡和格。
  3. 合成：前兩種都沒有可用的畫面才做，要使用者核可（重做照授權與上限）。送件時釘的首幀要和分鏡參考圖表的「首幀檔」是同一個檔（比內容）；重生首幀後把「首幀檔」改成新檔就好，不影響鎖。
  4. 無：參考模式只掛角色卡、場景卡（`3-提示詞.md` 範本 C）；不釘首幀，也不用 `after`。
- **首幀檔**：接力，或借的相鄰正式片段還沒生成，記 `PENDING PRODUCTION RELAY`。這不擋 G5B 通過，也不擋 G5C Animatic；但這一鏡真正送進 H3 正式佇列前，要解析成實際的檔案（佇列的 `after` 會等前一條完成、檢查過才取那一格送出，`4-生成與驗片.md` §1）。策略是「合成」的鏡：分鏡參考圖有首幀資格，就直接當首幀；沒有，就另做一張（`comfy.qwen_edit`，`size=(768,1344)`，要授權），提示詞和改圖照上面分鏡參考圖的合成。要停在指定構圖的鏡，另做尾幀，和首幀同機位。
- **首幀資格**，全部符合才是「是」：和 G4B 核可的分鏡卡一致——第 0 幀的起手狀態（動作卡 B）、景別、畫面邊界、角色身份、場景、站位、製作計畫（「生成」那一行：模式、拆段、尾幀）；768×1344。G5B 不拿還沒編譯的提示詞來判；首幀和提示詞的核對在第 3 站編譯後做（`3-提示詞.md` §2）。分鏡參考圖畫的是中段的表達點、不是第 0 幀的話，照樣給 Animatic 用，首幀資格寫「否」；不要為了兼任首幀，犧牲分鏡參考圖的敘事可讀性。
- 不管哪一種首幀：是動作開始前的那一刻，不是動作進行中；首幀是軟約束，景別、站位要和提示詞寫的一致，衝突時 H3 照文字走、首幀被蓋掉（`3-提示詞.md` §2）；用之前核對每一隻手屬於誰、道具數量和狀態、兩人距離（算 T1）、景別，和分鏡卡一致。定了以後回寫分鏡卡：景別、站位、動作卡 B。

### 分鏡參考圖表

登記在這份檔，每鏡一列，不另開文件。

| 欄位 | 寫什麼 | 誰會讀 |

### 一致性檢查（每一批）

- 美術：和 Style Master 並排看是同一部作品；人物身份、場景、服裝、道具照核可資產。
- 分鏡：景別、站位照 G4B；表達點讀得到；沒有新增故事內容；沒有提前揭曉。
- 連戲：人物位置、服裝、道具狀態和前後鏡合理。預覽不要求逐格一致。

### G5B 關卡

全部要有：每個要進製作的鏡都有一張分鏡參考圖，對應唯一鏡號（表裡正好一列）；美術、角色、場景、道具、構圖、敘事檢查都過；沒有提前揭曉；首幀策略明確、首幀資格判定了；沒有待做或待審的圖。G5D 鎖定前照表裡的參考圖狀態、美術檢查、構圖檢查、敘事檢查機械核對（§12），所以這幾欄要寫「核可」「過」，不寫別的說法。

關卡選項：核可分鏡參考圖，進 G5C／修改指定的圖／回到 G4B。

## 11. Animatic（G5C）

G5B 通過後、正式生成前做：用分鏡參考圖和預覽語音，照成片的順序和秒數把整集接起來看一遍。

- 要回答：故事不用解釋看不看得懂；鏡頭順序對不對，鏡數是不是都還需要；鏡與鏡之間的節奏；對白、旁白、心聲放不放得下；停留、延宕夠不夠；鏡與鏡之間的揭曉順序；相鄰兩鏡接不接得上。
- 不驗：H3 的畫質、表演、嘴型、運鏡、混音，也不要求逐格連戲。

### 輸入

只讀核可過的來源：

| 要什麼 | 從哪裡讀 |
|---|---|
| 畫面 | §10 核可的分鏡參考圖 |
| 順序、每鏡秒數 | `2-鏡頭表.csv` 的列順序和「秒數」 |
| 敘事和鏡頭內容 | G4C 通過的分鏡卡 |
| 音色 | §9 核可的音色檔 |
| 台詞、旁白、心聲的文字和說話人 | `1-劇本.md` 定稿、分鏡卡 |
| 聲音出現的時間 | 分鏡卡的時間預算（動作卡 J）、旁白窗 |
| 承載敘事的聲音 | 分鏡卡 2A 區塊的通道、動作卡 D（聽得見的觸發） |

G5C 不改台詞、不換說話人、不加旁白、不加鏡、不改順序、不改揭曉、不加故事資訊；要改的照下面的分流回去改。

### 畫面

- 每個要進製作的鏡，分鏡參考圖照鏡頭表的「秒數」放成一段靜態畫面。
- 鏡與鏡之間只用硬切。不加推拉、搖移、淡入淡出、轉場、假運鏡或其他動態效果，除非分鏡卡本來就要這個資訊。
- 分鏡參考圖是這一鏡的代表狀態，不是 H3 的第 0 幀。它常畫鏡內的表達點，卻從這一鏡第 0 秒一直放到最後，所以證明不了鏡內的先後：A 到 B 的變化、動作的順序、鏡內揭曉的時間、站位的推進。這些照 G4B 的動作卡、台詞窗、旁白窗判，不為此多做分鏡參考圖。

### 預覽語音

- 讓核可的對白、畫外人聲、心聲、旁白聽得到。它是衍生的預覽資產，不是新的劇本或音色來源：文字照 `1-劇本.md` 定稿和分鏡卡，聲音照 §9 的核可音色檔；不改寫台詞、不換聲音。
- 做法沿用 `comfy.h3_vo`：掛核可音色檔、只解音訊（`4-生成與驗片.md` §2）。旁白、心聲實際用過；拿來念對白【未驗證】。
- 每句一條，生成前照授權規則；驗收照 `5-結案.md` §2 第 5 步，另外聽字和定稿一字不差。
- 用 `驗片量測.py speech` 量出說話的起迄，剪到只剩說話的部分（前後留約 0.1 秒），存成 `2-預覽\語音_{鏡號}_{第幾句}.wav`。

### 承載敘事的聲音

- 聲音本身就是拍、資訊、觸發、威脅或推論的來源時（例：門外的鑰匙轉動聲、讓角色看到某件事的手機通知聲、門被重重關上），Animatic 要聽得到它，或明確標「未解」。哪些算，看分鏡卡 2A 區塊的通道和動作卡 D 的觸發。
- 有現成的音檔就放進那一鏡的 `overlays`；沒有就標未解，記進這一版的問題清單，不為此生成。
- 普通的環境聲、腳步、衣服摩擦、室內空氣聲不放，也不另建擬音流程。
- 某一拍要靠這個聲音才看得懂，而它還未解：「故事看得懂」不能判過。

### 時間的依據

- 「語速」（§9）不是時間軸的依據。還沒有預覽語音時，台詞長度只能照規則核心 §2.4 的字數換算來估，要標「估計」。
- 有了預覽語音，以剪好的檔案實際長度為準。
- 放不下時，不加速、不變速、不刪字、不吞停頓，先報問題，照原因回去改：鏡頭的秒數不合理 → G4B；台詞本身要縮短 → 劇情改動，回第 1 站，使用者核可（2A §15）。

### 時間軸檔與輸出

每一版一份時間軸檔 `2-預覽\animatic_vNN.json` 和一支 `2-預覽\animatic_vNN.mp4`，舊版不覆蓋。時間軸檔就是 `_腳本\剪接.py` 的設定，只記重建這一版要的東西，不是第二份劇本或分鏡：

```json
{
  "clips": [
    {"image": "2-分鏡圖/S01.png", "seconds": 3.2, "label": "S01"},
    {"image": "2-分鏡圖/S02.png", "seconds": 4.5, "label": "S02",
     "overlays": [["2-預覽/語音_S02_1.wav", 0.8, 0]]}
  ],
  "qc_overlay": true,
  "out": "2-預覽/animatic_v01.mp4"
}
```

| 欄位 | 從哪來 | 誰會讀 |
|---|---|---|
| `image` | §10 表的「分鏡參考圖」 | `剪接.py`：這一鏡的畫面 |
| `seconds` | 鏡頭表的「秒數」 | `剪接.py`：這一鏡的長度、後面每一鏡的起點 |
| `label` | 鏡號（必填） | QC 疊字、`--dry-run` 的時間軸；G5D 鎖定前照它和鏡頭表核對順序、圖、秒數（§12） |
| `overlays` | 預覽語音檔、鏡內的開口時間、增益 dB | `剪接.py`：放語音；超過這一鏡就警告 |
| `qc_overlay` | 審看版寫 `true` | `剪接.py`：畫面上印鏡號和時間碼 |
| `out` | `2-預覽/animatic_vNN.mp4` | `剪接.py` |

- 時間軸檔只放上表這幾欄。`剪接.py` 的 `speed`、`xfade` 在 Animatic 不用（硬切、不變速），寫了 G5D 鎖定前會擋（§12）。
- 鏡內的開口時間＝分鏡卡排定的時間（動作卡 J、旁白窗）減掉「成片取」的起點：Animatic 的一鏡就是成片取的那一段。
- 每鏡的起迄秒由 `剪接.py` 從 `seconds` 算，不另存。出片前先跑 `python _腳本/剪接.py 2-預覽/animatic_v01.json --dry-run`：印出每鏡的起迄和每條語音在鏡內的起迄，語音超過那一鏡會警告，不出片。
- 審看結果不記在時間軸檔：每一版改了什麼、使用者怎麼說、問題清單記在工單。使用者核可完整的那一版，記進關卡紀錄表 `G5C｜PASS｜那一版的 mp4 和時間軸檔`（§12）；工單只記經過，鎖定不拿它當依據。
- 出片照授權規則。鏡號和時間碼只疊在預覽影片上，分鏡參考圖原檔不動。不加敘事字幕，劇本本來就要畫面上有字的例外。

### 使用者驗收

看完整的 Animatic，至少判：
- 故事不用解釋就看得懂；
- 沒有多餘的鏡，也沒漏掉必要的拍；
- 節奏不會太快或太慢，停留、延宕的時間夠；
- 對白、旁白放得下；
- 相鄰兩鏡沒有跳太大，身體距離、站位的敘事看得懂；
- 鏡與鏡之間的揭曉順序沒有提前，伏筆和回收成立；
- 結尾有落點。

單張圖的美術細節這一步不評，除非已經妨礙看懂敘事。

### 問題分流

G5C 只列問題，不重新設計。照種類回到負責的那一層，只重做受影響的部分：

| 問題 | 回哪裡 |
|---|---|
| 故事、拍、鏡頭必要性、揭曉 | G4A／G4C |
| 秒數、站位、景別、機位、動作 | G4B |
| 分鏡參考圖表達不了核可的鏡 | G5B |
| 角色的聲音身份 | G5A |
| 台詞、說話人、旁白和心聲的內容 | 第 1 站（劇情改動，2A §15） |

改完只重做受影響的分鏡參考圖或預覽語音；要先看局部時，時間軸檔只留受影響的鏡和前後各一鏡出一支；最後再出一版完整的 Animatic 整集驗收。

### G5C 關卡

全部要有：
- 所有要進製作的鏡都在時間軸上，順序和鏡頭表一樣，每鏡秒數明確、分鏡參考圖核可過；
- 每句核可的對白、畫外人聲、心聲、旁白都有預覽語音的位置；承載敘事的聲音聽得到，或標了未解；說話人、旁白沒有未解的問題；沒有未解的放不下；
- 故事看得懂（某一拍要靠未解的聲音才成立，就不算過）、鏡與鏡之間的節奏和揭曉順序都過；鏡內的揭曉時間照 G4B 的時間設計，靜態圖不當證據；連戲足以進正式製作；
- 使用者核可完整的 Animatic。

關卡選項：核可 Animatic，進 G5D／修改指定問題（照分流）／回到 G4A。

## 12. Final Shot Lock 與正式生成關卡（G5D）

G5C 通過、使用者核可完整的某一版 Animatic 之後做：

G5C 通過 → G5D Final Shot Lock → 正式生成關卡通過 → 第 3 站編譯提示詞 → 第 4 站送件前檢查 → H3

Final Shot Lock 的意思是：這一版 Animatic 代表的正式製作計畫，使用者已經核可，可以開始正式製作。它不鎖 H3 片段、不鎖成片，也不鎖執行中產生的檔名。

### 鎖什麼

鎖的是製作計畫：

| 鎖定的計畫 | 在哪裡 |
|---|---|
| 核可的故事、定稿台詞、事件表 | `1-劇本.md` |
| 要進製作的鏡號、順序、秒數 | 鏡頭表 |
| 事件、敘事目的 | 鏡頭表「敘事目的」、分鏡卡的標頭和 2A 區塊 |
| 台詞、說話人 | 鏡頭表「台詞」、分鏡卡 |
| 站位、視線、手上道具 | 鏡頭表、分鏡卡 |
| 景別、畫面邊界、機位、運鏡 | 分鏡卡「景別」「機位」、動作卡 H |
| 動作卡 | 分鏡卡 A–K |
| 聲音、台詞窗、旁白窗 | 分鏡卡「聲音」、動作卡 J |
| 製作拆段：模式、幀數、A／B 段、成片取 | 分鏡卡「生成」 |
| 首幀策略 | 鏡頭表「首幀來源」 |
| 卡片（掛哪些、什麼順序）、風格句、美術段 | 分鏡卡「素材」、§1 |
| 核可的音色 | §9 音色資產表 |
| 每鏡用哪一張分鏡參考圖 | §10 分鏡參考圖表 |

執行中的狀態不鎖，改了不會讓鎖失效：

- 鏡頭表的「狀態」（待生成、生成中、待審、過…）、「重做次數」、「備註」；
- 輸出檔名、日期、生成時間、seed、條數；
- 首幀檔：`PENDING PRODUCTION RELAY` 解成實際檔案，或照重做規則重生的首幀——前提是首幀策略沒變。

會影響製作的內容不能只寫在「備註」。

### 每個事實只有一個家

正本只有一個；鏡像只能從正本推，鎖定前核對一致，對不上就不能鎖，也不算第二個來源：

| 事實 | 正本 | 鏡像 |
|---|---|---|
| 故事、定稿台詞、事件表 | `1-劇本.md` | 鏡頭表「台詞」、分鏡卡的台詞（第 2 站照劇本抄） |
| 要進製作的鏡、順序、秒數、首幀策略 | `2-鏡頭表.csv` | §10「首幀策略」 |
| 這一鏡要掛哪些參考圖、什麼順序 | 分鏡卡「素材」的資產 ID | 鏡頭表「參考圖」、資產表「用在」 |
| 這一鏡要掛哪些音色 | §9「使用鏡頭」（沒加註的） | 分鏡卡「素材」的 Voice ID（順序＝<Audio N>） |
| 資產是哪個檔、核可了沒 | §2 資產表 | — |
| 音色是哪個檔、核可了沒 | §9 音色資產表 | — |
| 哪些關卡過了、核可的是哪一版 Animatic | 關卡紀錄表（G3A、G4C、G5C）和 §2、§9、§10 的狀態欄 | 工單只記經過 |

### 正式生成關卡

整部片能不能開始正式生成，看這幾項；不能因為檔案都在就算過：

- G3A 美術鎖定、G3B 需要的資產、G4C 敘事驗收、G5A 音色資產、G5B 分鏡參考圖、G5C Animatic 都通過；作品沒有任何出聲的身份時，G5A 是空的也算通過；
- 寫得出使用者核可的是哪一版 Animatic；
- 沒有未解的劇情、音色、分鏡參考圖、時間問題；
- Final Shot Lock 存在，而且還有效。

### 鎖定前置

鎖定的依據只有 `1-劇本.md`、`2-鏡頭表.csv` 和這份檔，工單不算。`python _腳本/檢查量產Gate.py ready --animatic … --manifest …` 逐項核對（不寫檔），任何一項缺就不能鎖：

- 關卡紀錄表（放在專案這份檔最前面，三欄「關卡」「狀態」「依據」）：`G3A｜LOCKED`、`G4C｜PASS`、`G5C｜PASS`，而且 G5C 的依據裡列的就是這次要鎖的 Animatic 和時間軸檔——使用者核可的是哪一版，就只能鎖那一版。
- G3B：要進製作的鏡在「素材」引用到的資產都在資產表、狀態＝核可、檔案在；資產表 ID 不重複。
- G5A：使用鏡頭列到要進製作的鏡的音色都是核可、核可檔找得到；Voice ID 不重複；加註和核可用途一致。
- G5B：分鏡參考圖表裡每個要進製作的鏡正好一列，參考圖狀態＝核可，美術檢查、構圖檢查、敘事檢查＝過。
- G5C 的時間軸檔和鏡頭表一致：一鏡一段、`label`＝鏡號、順序同鏡頭表、`image`＝§10 那一鏡的分鏡參考圖、`seconds`＝鏡頭表的秒數（換成影格比，fps 照時間軸檔、預設 24）、每段不變速也不交叉淡化（`speed` 省略或 1、`xfade` 省略或 0）；漏鏡、多鏡、重複、順序錯、錯圖、秒數不同、變速、淡化都不能鎖。
- 鏡像和正本一致：鏡頭表「參考圖」＝素材的資產 ID；素材的 Voice ID＝§9 在這一鏡出聲的；§10「首幀策略」＝鏡頭表「首幀來源」。
- 三個指紋算得出來。

```text
| 關卡 | 狀態 | 依據 |
|---|---|---|
| G3A | LOCKED | 使用者 2026-10-06 鎖定美術；Style Master 資產/風格母版.png |
| G4C | PASS | 2026-10-06 問題清單清空 |
| G5C | PASS | 2-預覽/animatic_v03.mp4、2-預覽/animatic_v03.json；使用者 2026-10-07 核可 |
```

前置都齊了，給使用者一張鎖定卡：核可的 Animatic 版本、鏡數和總長、用到的音色、例外。使用者說「鎖定」，才跑 `python _腳本/檢查量產Gate.py lock --animatic … --manifest … --user "使用者的原話和日期"` 寫 `量產關卡.json`；`--user` 的原話裡要有「鎖定」才鎖（記進 `locked_by_user`），「OK」「繼續」「可以」都不是鎖定；lock 會再跑一次前置，程式不會因為檔案齊全就自己鎖。鎖定之後，三個指紋都對得上，關卡就維持通過。關卡選項：鎖定，進第 3 站／回到指定的層。

### 量產關卡.json

放專案資料夾最上層，只記關卡狀態和來源的指紋，不抄劇本或分鏡的內容。

```json
{
  "schema_version": 1,
  "state": "LOCKED",
  "locked_at": "2026-10-07T15:30:00+08:00",
  "locked_by_user": "使用者 2026-10-07：「鎖定」",
  "approved_animatic": "2-預覽/animatic_v03.mp4",
  "approved_animatic_manifest": "2-預覽/animatic_v03.json",
  "shot_table_hash": "sha256:…",
  "production_plan_hash": "sha256:…",
  "animatic_manifest_hash": "sha256:…",
  "exceptions": []
}
```

| 欄位 | 寫什麼 | 誰會讀 |
|---|---|---|
| `schema_version` | 這份檔的格式版本 | 關卡檢查 |
| `state` | `LOCKED`／`INVALID` | 關卡檢查、送件前檢查、出片授權卡 |
| `locked_at` | 使用者說「鎖定」的時間 | 出片授權卡、工單 |
| `locked_by_user` | 使用者說「鎖定」的原話和日期（要有「鎖定」） | 出片授權卡、工單、稽核 |
| `approved_animatic` | 使用者核可的那一支 Animatic | 出片授權卡、工單 |
| `approved_animatic_manifest` | 那一支的時間軸檔 | 關卡檢查：重算 `animatic_manifest_hash` |
| `shot_table_hash` | 鏡頭表的指紋 | 關卡檢查 |
| `production_plan_hash` | 製作計畫的指紋 | 關卡檢查 |
| `animatic_manifest_hash` | 核可的時間軸檔的指紋 | 關卡檢查 |
| `exceptions` | 使用者授權的例外（見「例外」） | 關卡檢查、送件前檢查 |

- 沒有這份檔，或 `state` 不是 `LOCKED`：H3 影片一律不送，例外除外。
- 三個指紋由 `檢查量產Gate.py` 照下面的範圍算，不手寫：`fingerprint` 印出現在的指紋，`check` 和鎖定時的比。
- 工單記每一次鎖定和失效的經過；關卡以這份檔為準。

### 指紋的範圍

不能整份 `2-分鏡.md` 一起算：執行中合法的變動，像 `PENDING PRODUCTION RELAY` 解成實際檔案，不能讓鎖失效。

| 指紋 | 算進去 | 不算 |
|---|---|---|
| `shot_table_hash` | 鏡頭表每一列（照順序）的全部欄位，照欄名排除執行中的三欄和衍生的「參考圖」（不看欄的位置） | 「狀態」「重做次數」「備註」；「參考圖」（素材的鏡像，鎖定前核對一致） |
| `production_plan_hash` | `1-劇本.md` 全文（故事、定稿台詞、事件表：Story Truth 只有這一份，不另抄進關卡檔）；每個要進製作的鏡的分鏡卡全文（「鏡號｜」那一行到下一張卡或下一個標題；同一鏡有兩張卡就不能鎖）；視覺聖經「風格句」那一列；美術段（**美術段 那一行到下一個標題）；要進製作的鏡在「素材」引用到的資產內容（照資產表的 ID 找檔案，同一份只算一次；資產表 ID 重複、引用不存在的 ID 都不能鎖）；音色資產表裡「使用鏡頭」和要進製作的鏡有交集的列（含加註心聲、旁白的；表頭「Voice ID」「核可檔」「核可用途」），核可檔算檔案內容；§10 每鏡用哪一張分鏡參考圖、首幀資格 | 沒被引用的資產；沒被使用的音色；敘事帳；關卡紀錄表；§10 的「首幀檔」；各表的狀態欄 |
| `animatic_manifest_hash` | 核可的時間軸檔，加上它引用的每個圖檔、聲音檔的內容 | Animatic 影片檔本身：同一份時間軸檔和素材就能重出 |

算之前先正規化：文字一律 UTF-8，BOM、CRLF／LF、行尾空白、前後空行不算；鏡頭表照欄名讀，欄的先後不算，列的順序照原樣；時間軸檔解析後比，鍵的順序、3 和 3.0 不算差別，陣列照原順序；檔案比原始內容（SHA-256）；路徑一律換成相對專案資料夾、用 / 分隔。只改格式、沒改內容時，指紋不變。

### 失效

鎖定之後，製作計畫任何一項改了，鎖就失效（`INVALID`）：加刪鏡、換順序、改秒數、改劇本（故事、台詞、事件表）、換說話人、改站位、景別、機位、動作卡、首幀策略、製作拆段、換音色、換分鏡參考圖或卡片。換一版 Animatic 也一樣：時間軸檔或它用到的檔變了，舊的核可不能沿用到新版。

- 存的狀態和實際的關卡分開：存的狀態是 `量產關卡.json` 的 `state`（`LOCKED`／`INVALID`）；實際的關卡＝存的是 `LOCKED`，而且三個指紋都對得上。
- 指紋對不上：實際的關卡不過，並說出是哪一個；檢查程式不改存的狀態，內容改回鎖定時的樣子就又對得上。
- 使用者真的決定改鎖定的內容：跑 `檢查量產Gate.py invalidate --reason …`，存的狀態改成 `INVALID`，之後內容改回原樣也照樣擋，要等新的 lock。沒有改回 `LOCKED` 的命令。
- 重新鎖定：回到負責的那一層修 → 重跑受影響的檢查 → 重出 Animatic → 使用者重新核可完整的一版 → 新的 Final Shot Lock（重寫這份檔）。
- 只有執行中的狀態變了，不用重做 Animatic。
- 正式生成開始後，使用者要改鎖定的內容：立刻跑 invalidate。已經做好的合法片段不刪；佇列裡還沒送出的受影響鏡用 `cancel` 取消；重新鎖定之前不送新的 H3 影片。

### 擋什麼、不擋什麼

- 擋：H3 影片生成（`h3_ref`、`h3_i2v`；正式、base20、草稿檔位都算）。關卡通過、那一條也過了送出前的送件前檢查（`4-生成與驗片.md` §1）、拿到那一次發的一次性通行證才送。
- 不擋：Qwen 生圖和修圖（卡片、分鏡參考圖、首幀）、音色候選和音色資產（`h3_voice`）、預覽語音和旁白（`h3_vo`）、重出 Animatic、`--dry-run`、lint、離線檢查和量測。不擋的是能不能跑；跑完改到鎖定的內容（例：換了卡片），鎖照樣失效。
- 關卡管的是整部片：接力鏡的前一鏡末格還沒有，不擋整部片開工；那一鏡的首幀由送件時的送件前檢查看。

### 例外

測試或研究要繞過關卡跑 H3 影片（還沒鎖，或要跑鎖定計畫以外的東西）：要使用者明確授權，記進 `exceptions`，範圍要小。不能整個專案關掉關卡，也沒有不記紀錄的繞過。

```json
{"id": "EXC-001",
 "scope": {"shots": ["S01"], "profiles": ["draft"], "takes": 3},
 "reason": "S01 景別測試",
 "authorized_by_user": "使用者 2026-10-07：「例外：S01 草稿跑 3 條測景別」",
 "timestamp": "2026-10-07T10:00:00+08:00"}
```

- `id`：`python _腳本/檢查量產Gate.py exception --shots S01 --profiles draft --takes 3 --reason … --user …` 記例外時自動給（EXC-001…）；送件的 meta 寫 `"例外": "EXC-001"` 才用得到。
- `scope`：哪幾鏡、哪個檔位（formal、base20、draft；`h3_i2v` 是 i2v）、幾條。真的送到 ComfyUI 才算用掉一條，排了又取消不算；用掉幾條從佇列帳本和生成紀錄算。用完就不再放行，新的測試要新的例外。
- `reason`：為什麼要繞過。
- `authorized_by_user`：使用者授權的原話和日期。原話裡要有「例外」和範圍內的每個鏡號（例：「例外生成 S05 草稿 2 條」），`exception` 才記得進去；手改進關卡檔的，送件時擋 `EXC_USER_TEXT`。「現在就送」「先跑看看」「直接生成」都不是例外授權：先給使用者看例外確認卡（鏡、條數、檔位、預估時間、繞過了哪些關卡），等他明確說「例外」。
- `timestamp`：記下這條例外的時間。
- 例外是計畫以外的測試：不比模式、幀數、拆段、首幀來源和音色；提示詞、lint、參考檔照樣要過，給了 `after` 時換圖節點和送出前那一格也照樣核對。
