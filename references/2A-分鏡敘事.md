# 2A 分鏡敘事（第 2 站：從事件到鏡頭之間的敘事規劃）

> 來源標記（必要時才標；沒標的是本檔的規則）：【既有規則】repo 已有的正式規則｜【H3 已驗證】本機實測過｜【盲測】多個獨立評審判斷一致，只證明判斷穩定，不代表 H3 做得到｜【未驗證】H3 沒有實測。

## 1. 用途與邊界

把核可的劇本與事件表，轉成一組**最少但足夠、每一鏡都有敘事價值**的分鏡：先回答「這裡有什麼值得拍、觀眾真正要感知什麼、用什麼畫面表達最有效」，再交給 `2-分鏡.md` 決定怎麼拍。本檔不處理站位連戲、機位、運鏡、焦距、H3 提示詞、資產和首幀；不是電影理論，也不是景別公式；不為電影感加鏡。

## 2. 責任與流程

| 誰 | 擁有 |
|---|---|
| 第 1 站 | 故事真相、核可事件與順序、台詞與說話者、動機、揭曉與反轉、角色知情；以及劇本或事件表寫明的角色動作和執行者、人聲、資訊由哪個事件或行為交付、有敘事意義的道具行為與在場人物（§15） |
| 2A（本檔） | 每一鏡的拍、類型、表達點與表達方式、Visual Scale、鏡頭功能；刪除與簡化的判斷；劇情改動只提出，不套用 |
| `2-分鏡.md` | 站位、視線、景別、機位、焦距光圈、動作卡、聲音、首幀、連戲 |
| Camera DSL skill（選用） | 只選框法和運鏡寫法，不決定敘事 |

```text
第 1 站事件 → 拍 → 有效性（五種類型、刪除測試、簡化測試）→ 表達點 → 表達設計
→ Visual Scale → 鏡頭功能 → 2-分鏡.md（站位、視線、景別、機位、焦距、動作卡、首幀）→ 3-提示詞.md → H3
```

## 3. 最高判準

每一鏡都要說得出：觀眾在這一鏡實質得到什麼、刪掉會少什麼、有沒有更簡單更可靠的做法。說不出來的不拍。

每一刀也要有理由：下一鏡的表達點變了，或時間、地點、人物線變了。生產拆段是技術刀，不算敘事上的新鏡（§6）。

## 4. 拍

- **定義**：拍＝讓故事世界或觀眾產生可辨識改變的時刻，寫成「主體：A → B」。「他說了一句話」不一定是拍；「他說完，她第一次開始懷疑他」才是。
- **推動軸**：至少推動一項。
  - 故事世界：故事、人物、關係、衝突（事件表的「開始→結束」已經記了大半）；
  - 觀眾：理解、期待、情緒（事件表的「多懂了什麼」已經記了大半）。
- **一拍一鏡**：一個事件可以有幾個拍；一拍原則上一鏡，一鏡一個主要變化【既有規則：規則核心 §2.1】。
- **獨立拍檢查**：用來判斷 X 是另一個拍，還是 Y 的前段、觸發、準備動作或支持線索。X 只有在自己已經形成一個獨立、值得觀眾先讀完的 A→B 改變，而且 Y 的意義依賴這個新狀態時，才算另一個拍。依序問：
  - A. 畫面停在 X，觀眾是否已經得到一個完整、可單獨描述的敘事改變？
  - B. Y 的意義，是否需要觀眾先讀完 X 這個改變？
  
  判定：
  - A 是、B 也是 → 兩個獨立拍，不得因為同一事件就合併；
  - A 否 → X 是 Y 的前段、觸發、準備動作或支持線索，可以合併；
  - A 是、B 否 → Y 不依賴 X，這本身不構成拆鏡的理由；再看 X 有沒有必須讓觀眾獨立讀懂的表達點（§6）：沒有 → 可以同一鏡；有 → 拆；判斷不了 → 問；
  - 判斷不了 → 問。

## 5. 五種類型

只用這五種。有拍的是推進；沒有新事實的鏡，要屬於另外四種之一，而且前提成立。

| 類型 | 用在 | 前提（不成立就不能用這一類） |
|---|---|---|
| 推進 | 有 A → B | 推動至少一項 |
| 延宕 | 沒有新事實，刻意延後答案 | 有尚未解開的問題，結果值得在意；延遲讓期待、壓力或不確定性增加；只能用既有的拍或停留，不為節奏灌時間，不加故事沒有的事件 |
| 停留 | 沒有新事實，讓剛發生的情緒高點、決定、結果或重要反應落地 | 緊接那一刻。能用前一鏡的出點完成就合併，不另加鏡；同一種情緒連續兩鏡、表達點又沒變，視為重複 |
| 定向 | 沒有新事實，建立後續理解需要的方位 | 新地點、新時間、新人物線、在場人物改變、主觀段落切換、重要空間關係改變。已經交代過而且沒變，就不加例行的建立鏡 |
| 呼應 | 已核可內容再次出現：伏筆回收、對照、母題、變奏、callback | 說得出這次重現多了什麼新意義，或回收了什麼；靠大尺度元素對上，不靠細節。說不出來就是重複 |

好奇、懸念、驚奇不是類型。它們是問題的性質或揭曉的效果，寫在拍裡就好（例：「開問題：她會借嗎？」「收問題」）。

## 6. 表達點

- **定義**：表達點＝觀眾實際透過哪一個畫面、動作、表演、台詞、聲音或空間關係，感知到這一拍的改變。
- **數量**：每鏡一個主要表達點，最多兩個支持線索（§7）。
- **拆或不拆**：兩個互相競爭、都必須被讀懂的表達點，要拆成兩鏡（敘事拆）。一次生成控制不住先後順序時，拆成 A、B 兩段生成，這是生產拆段，敘事上仍是一鏡【既有規則：2-分鏡 §5】。兩種拆法分開寫。
- **通道**：表達點靠什麼被讀懂——台詞、表演、聲音、畫外人聲、畫外視線、大尺度走位、身體距離、空間關係、進出畫、大型道具。這只是描述，不是新的指令語法。哪些通道可靠，見 §16。

## 7. SUPPORT 與 PLANT

支持線索只有兩種角色：

- **SUPPORT**：現在就幫表達點被讀懂。
- **PLANT**：現在不承擔主要理解責任，登記進呼應帳（§18），之後回收。
  - 不得承擔當下必要的劇情。
  - 不得靠小字、精確數量、微小物件差異、跨鏡細節比對，或 H3 不可靠的微表情。
  - 可行的方向是大尺度構圖、身體距離、聲音母題、大尺度走位、明顯的空間關係【盲測：評審種的 PLANT 都是這幾類】。

## 8. 刪除測試：刪（DELETE）和合併（MERGE）

先問：刪掉這個敘事內容，觀眾會實質少掉什麼？可能的損失有理解、因果、人物、關係、衝突、期待、張力、情緒、定向、呼應、伏筆回收、表達強度。

| 判定 | 定義 |
|---|---|
| **刪** | 這個鏡頭承擔的敘事內容本身被移除 |
| **合併** | 內容仍然存在，只是移進鄰鏡、前一鏡的出點停留、下一鏡的 A 段，或在同一鏡內完成 |

- 內容能完整移進鄰鏡，或已經由其他鏡完整承擔（敘事功能被吸收）→ 合併，不是刪。刪只用在：這項內容本身不必保留，也不需要任何鏡承擔。
- 完全說不出損失 → 高度疑似該刪。
- 失敗的標準是**必要內容遺失**（Necessary Content Loss）：必要的理解、人物變化、關係、衝突、期待、情緒、定向、延宕、呼應、伏筆回收或表達點真的消失了，才算誤刪。原本的鏡號不存在，不算誤刪。

## 9. 簡化測試

即使有效，也依序問一次，有更簡單而且不損失敘事的形式，就用更簡單的：
1. 能併進上一鏡、下一鏡，或在同一鏡內完成嗎？
2. 能改用出點停留嗎？
3. 已有的台詞是不是已經夠了？
4. 是不是只換了景別、角度，或多一個運鏡？
5. 是不是同一種情緒再演一次？

## 10. 表達設計：需要觀眾自己推論時

表達點要觀眾自己推論（而不是直接告訴他）時，三件事都要成立：
1. 推論目標寫得出來（觀眾應該推出什麼）。
2. 至少兩個互相支持、production-safe 的線索或通道。
3. 不會被合理地讀成另一個完全不同的意思。

只有一個弱線索 → 改通道；改通道就要動核可內容 → 問。

不另設「直述／引導」欄：這個標記本身判斷不穩，通道的選擇才穩【盲測】。

## 11. Visual Scale：跟著表達點走

不由拍的種類決定。沒有「情緒 → FACE」「決定 → FACE」「關係 → BODY」這種對照【盲測：純情緒和決定的情境，評審選了 BODY；雙人與群體關係選了 SPACE】。

決定順序：表達點 → 它靠什麼被讀懂 → 觀眾需要看多大的範圍 → Visual Scale。

| 尺度 | 表達點落在 | 景別候選（`2-分鏡.md` §6 的名稱） |
|---|---|---|
| SPACE | 空間、人物距離、群體關係、相對位置、進出畫、大尺度環境變化、改變後的整體局面 | 遠景、全景 |
| BODY | 身體動作、走位、坐站、靠近或退開、雙人互動、肢體距離、明確的姿態改變。純情緒和決定也常在這裡，不要因為「情緒」就切臉 | 中全景【未驗證】、中景 |
| FACE | 人臉上可可靠辨識的反應、理解、認知轉折、明確的表情改變 | 中近景、近景（特寫少用） |
| DETAIL | 單一局部資訊本身就是不可替代的表達點 | 大特寫、物件插入鏡【未驗證】 |

- **FACE**：不要靠微表情、眨眼、細小的肌肉變化。眨眼文字控制不住【既有規則：`4-生成與驗片.md` §3、§5】；微表情能不能穩定生成【未驗證】。
- **DETAIL** 必須另外過 H3 可靠度關卡：核心資訊只能靠小物件、可讀文字、精確數量、精細手部或微小差異，又沒有安全的替代 → 問使用者，不能自己改故事【既有規則：規則核心 §1.1–§1.3】。

**鏡頭功能**：交給鏡頭層的一個詞，寫畫面必須有什麼內容。
- 交代：地點、在場的人、相對位置；
- 動作：有人做出改變，含入畫、轉身、開門；
- 說話；
- 注意：某人的注意力移向某處，常在畫外；
- 反應；
- 呈現：被看見的東西、人或結果本身。

## 12. 景別：最寬「有效」

選仍能完整保存表達點的敘事強度、注意優先、必要上下文的**最寬**景別。不是「最寬可讀」：只求看得到，盲測裡會系統性偏寬一級。

每次都做雙向檢查：

| 再寬一級 | 再近一級 |
|---|---|
| 表達點還清楚嗎？還是主要的注意目標嗎？ | 會得到什麼新的、說得出來的必要敘事價值？還是只是看得更大？ |
| 支持資訊會不會搶走重點？ | 會不會丟掉人物關係、身體語言或空間關係？ |
| H3 還能可靠表達嗎？ | |

- 近一級說不出新的敘事價值，就不靠近。
- 景別的理由要說得出三件事：為什麼這個尺度讓表達點最有效、更寬失去什麼、更近增加什麼；不得沒有理由地系統性偏寬或偏近。
- 不加「情緒高點固定近一級」，也不接受「H3 一律更寬」：每一鏡照雙向檢查決定。
- 「更有電影感」不能當景別理由。
- 雙向檢查的結論，寫進分鏡卡原有的「為什麼這樣拍」（即 Camera Intent，§18）。
- **反應鏡**：反應只有在它本身就是主要表達點，而且無法在目前的鏡頭內清楚完成時，才另給一鏡；景別仍由 Visual Scale 決定，不預設反應＝中近景。
- 照舊適用【既有規則】：收尾不推臉部特寫、9:16 用縱深調度、同一人連續兩鏡角度差 30° 以上，或景別差兩級（或差一級再加 30°）。後兩條是確定要切之後的連戲條件，本身不構成切鏡的理由。

## 13. 對話與反應：拍改變發生的地方

不用「誰說話就拍誰」當預設。先問：這一拍真正的改變發生在哪裡？
- 改變在聽的人身上（被刺到、愣住、懂了）→ 可以拍聽的人，說的人放在畫外【H3 已驗證：畫外人聲，規則核心 §7.25】。
- 重要的是兩人的距離或權力 → 拍兩人的關係（BODY 或 SPACE）。
- 重要的是說話的人的決定或意圖 → 才優先拍說話的人。

不切在台詞中間：聽的人的反應放在句子說完後，或另一鏡【既有規則：規則核心 §2.5】。

例：一個角色替別人轉述一句壞消息。
- 表達點是「話說出口」→ 拍說的人；
- 表達點是「聽的人的希望落空」→ 拍聽的人，說的人放畫外。
- 兩種都說得通，照表達點選；選哪一種都不改核可的台詞和說話者。

## 14. 建議的敘事模式

模式只是導演參考，不是規則；要不要拍，一律由 §5、§8、§9、§17 判斷。

**「全→中→近→特→全」翻成功能**：全＝定向（ORIENT）→ 中＝看互動（INTERACT）→ 近＝讀人物狀態（READ）→ 特＝隔離關鍵資訊（ISOLATE）→ 全＝改變後重看全局（RECONTEXTUALIZE）。

- 五個功能都成立，才會自然形成這個序列。實際場景通常只需要其中 2–3 個。
- 【盲測】四段測試場景都不需要 ISOLATE，硬加的特寫三個評審 20／20 都判為無效鏡。因此 ISOLATE 必須有真正不可替代的局部表達點，不得因 Pattern 要求而加入。
- 可以近景開場、沒有全景、沒有特寫、不回全景、只用兩三種尺度。

**常見模式**：每一步都要通過刪除測試；不是每一步都要獨立成鏡。

| 模式 | 步驟 |
|---|---|
| 基本推進 | 定向 → 看互動 → 讀人物 → 重看全局 |
| 發現 | 注意到 → 解讀 → 反應 → 確認或修正 |
| 揭曉 | 保留 → 加壓 → 揭曉 → 反應（揭曉的位置屬第 1 站；本模式只處理核可位置之前怎麼保留、怎麼加壓） |
| 關係對照 | A 的狀態 → B 對照 → 再看 A → 意義改變 |

## 15. 劇情安全

**第 1 站核可的內容**（§2）：
- 故事真相、事件、台詞、動機、揭曉、反轉；
- 劇本或事件表寫明的角色動作和誰執行、說話者、已寫明的人聲、資訊由哪個事件或行為交付、有敘事意義的道具行為與在場人物。

第 2 站不可以靜默替換這些內容。production-safe 的替代方案可以提出；只要需要動到核可內容，就不套用，判定寫「問」，並寫出四項：原本、建議、理由、不改的代價。

**新增聲音**：
- 執行音效（Foley）：只同步、強化已核可而且畫面裡本來就有的動作，不新增原因、資訊、角色知情、畫外事件、行動觸發或新的敘事推論 → 不算劇情改動，交給聲音與後製。
- 承載敘事的聲音：新增原因、畫外事件、提示、角色知情、行動觸發、威脅或新的敘事推論 → 核可內容改動 → 問。例：原劇本只寫「他掏手機」，自行加上「手機震動，所以他掏手機」＝新增原因 → 問。

例【盲測：審稿時最常見、又最常沒申報的兩種替換】：
- 「替對方整理衣領」改成「扶對方坐下」：即使比較好生成，也是替換核可動作 → 問。
- 「讓觀眾讀信」改成「畫外人聲念信」：新增人聲通道 → 問。

**權限**：
- 2A 自己加的鏡（不對應核可事件的反應、定向、延宕鏡）：可以直接刪或合併。
- 對應核可事件的鏡：
  - 刪＝劇情改動 → 問【既有規則：`4-生成與驗片.md` §4】；
  - 跨事件合併（兩個事件併進一鏡）→ 問【既有規則：`1-劇本.md` §3 第 3–4 條、`2-分鏡.md` §3】；
  - 同一事件內的合併：先做 §4 的獨立拍檢查。判定可以合併或可以同一鏡時，直接合併，並在鏡頭表備註寫明；判定是兩個獨立拍或要拆時，不得因為同屬一個事件而合併。

## 16. H3 生產安全

- **【H3 已驗證】**：台詞逐字不改；畫外視線（規則核心 §7.16）、畫外人聲（§7.25）；兩人站位與距離變化（§7.12–§7.13）；固定鏡、只寫起止景別的推鏡（§7.22）；靜止加反應（§7.21）；整場表情寫成角色宣告（§7.27，實戰驗證）；「說完停頓再動作」拆 A、B 兩段（§7.28、`2-分鏡.md` §5，實戰驗證）；心聲、旁白走後製（`5-結案.md` §1）。
- **景別**（單人、固定鏡、9:16、124 幀；草稿 3 seed＋正式 2–3 seed，沒有一級達到正式 3/3）：遠景、全景、中景、中近景、近景、特寫，照 `3-提示詞.md` §4 寫；正式檔位偶爾差一級，逐級結果見 `2-分鏡.md` §6。
- **【既有規則】不承擔劇情**：可讀文字與後期上字、小物件細節、精確數量、精確切點、鏡子細節、手逐件操作道具、要觀眾跨鏡比對的細節（規則核心 §1.1–§1.3）；眨眼（`4-生成與驗片.md` §3）。
- **【未驗證】**：微表情、藏臉（全程背對、越肩藏臉）、焦點轉移揭露、表情和台詞語意相反、被描述的道具保持不顯眼、複雜的前後景同時給線索、特定的聲畫反差、多人同步反應、低光下的表演、主觀運動鏡。

【未驗證】的通道可以用，但分鏡卡要標【未驗證】，判定標準在生成前寫死【既有規則：規則核心 §8.3】。【盲測】只證明判斷穩定，不能當成 H3 做得到的證據。

## 17. 判定流程

分三段做，順序不跳。

**A. 敘事候選判定**：依序檢查，得出候選就停；1–7 都沒有觸發，候選就是保留。
1. **拍與類型**：寫得出拍嗎？寫不出，是不是延宕、停留、定向、呼應，而且前提成立（§5）？都不是 → 刪。
2. **刪除測試**：說不出損失 → 刪；內容能完整移進鄰鏡、出點停留或 A 段 → 合併（§8）。
3. **重複**：同一敘事內容或推論已由其他鏡完整承擔，本鏡沒有新增意義；或和鄰鏡只差景別、角度、運鏡 → 合併（敘事功能由既有的鏡吸收）。
4. **競爭**：一鏡有兩個都必須讀懂的表達點 → 拆（敘事拆，不是生產拆段）。
5. **通道**：表達點走 §16 不可靠的通道，或要靠推論卻通不過 §10 → 改通道。
6. **禁露**：會提前露出要保留的資訊 → 刪（這一鏡就是為了露出它）或改通道（換掉露出的部分）。
7. **簡化**：有更簡單、不損失敘事的形式（§9）→ 合併。

合併只在內容真的能完整移過去，或已經由別鏡承擔時成立；同一事件內還要通過 §4 的獨立拍檢查，不通過就不是合併候選。

**B. 劇情安全關卡**（每一鏡必過）
候選判定或任何建議，只要碰到核可內容（§15），一律改成「問」，不自動執行。碰到的意思是：
- 替換、刪除或新增動作、執行者、說話者、人聲、台詞、在場人物、事件順序、揭曉位置；
- 新增承載敘事的聲音（§15）；
- 刪除核可事件；
- 跨事件合併。

**C. 接到鏡頭**（通過 B 之後）
8. **Visual Scale**：跟著表達點（§11）；DETAIL 過不了 H3 關卡又沒有替代 → 問。
9. **景別**：做雙向檢查（§12），結論寫進「為什麼這樣拍」。
10. **最終判定**：保留、合併、刪、拆、改通道、問，只有這六種。

## 18. 最小輸出

加在 `2-分鏡.md` 每一張分鏡卡上，緊接原有的標頭；不另開一份資料。

```text
{鏡號}｜{事件編號}：{觀眾這時多懂了什麼}        ← 原有標頭
拍：{主體}：{A} → {B}｜{類型}｜推動 {一兩項}
表達點：{…}｜通道 {…}｜支持 {SUPPORT：…／PLANT：…，最多兩個}｜（要保留資訊時加）禁露 {…}
刪除損失：{…}｜更簡形式：{無／併入 Sx／前一鏡出點停留…}
尺度：{SPACE／BODY／FACE／DETAIL}｜功能：{交代／動作／說話／注意／反應／呈現}
判定：{保留／合併／刪／拆／改通道／問}｜劇情改動：{無／問題 n}
為什麼這樣拍：{…}                                ← 原有欄位，即 Camera Intent：尺度和景別怎麼服務表達點，寫雙向檢查的結論
```

- 明顯有效的鏡，每欄寫幾個字就夠。
- 鏡號、事件編號、景別、機位、焦距照 `2-分鏡.md` 原有欄位，不重寫。
- 鏡頭表（`2-鏡頭表.csv`）不加欄位。合併或刪掉的鏡從鏡頭表拿掉，在吸收它的那一鏡的備註寫明。

**每集一份敘事帳**，放在分鏡卡的最前面：

```text
未解問題：Q1 {問題}｜開 {Sx}｜收 {Sy／刻意不收／留到下集}
呼應帳：{元素}｜PLANT {Sx} → 回收 {Sy}｜回收時多了什麼意義
```

延宕要靠「未解問題」證明前提成立；PLANT 和呼應要靠「呼應帳」。

## 19. 直接問使用者的情況

- 核可資料互相矛盾；在場人物不明；時間線衝突；首幀和前一鏡的連戲衝突。
- 關鍵事件只能靠 H3 不可靠的通道；DETAIL 是核心劇情，但 H3 做不出來。
- 需要替換核可動作、新增或修改人聲、修改台詞、移動揭曉、新增事件、發明誤導。
- 對應核可事件的鏡要刪或跨事件合併。
- 判斷不了兩鏡是必要的變奏還是重複；判斷不了是另一個拍還是前段（§4）；判斷不了新增的聲音是不是承載敘事（§15）。

問法用 SKILL.md 的三段式：哪一鏡或哪一站；一句白話說發生什麼；兩個選項讓使用者挑。劇情改動的提案，另外附上原本、建議、理由、不改的代價。不另設信心分數。

## 20. 交接給 `2-分鏡.md`

- **`2-分鏡.md` 收到**：每鏡的表達點、Visual Scale、鏡頭功能、支持線索、禁露、出點需求（停留或延宕要留的秒數）、判定。
- **`2-分鏡.md` 自己決定**：站位、視線、景別（在 Visual Scale 的候選內，照 §12 做雙向檢查）、機位、焦距光圈、動作卡、聲音、首幀、要不要生產拆段。
- **停留和延宕的秒數**：寫進動作卡 K（成片取哪一段），細剪時當成核可過的停頓，不剪【既有規則：`5-結案.md` §6「台詞、動作和核可過的停頓都不剪」】。
- **Camera DSL skill（選用）**：收到的鏡頭功能視為已經決定，只選框法和運鏡寫法。

## 21. 範例

1. **合併（同一事件內）**：角色放下手上的東西、叫對方的名字，下一鏡才真正開口提問。照獨立拍檢查，「叫名」停下來時沒有一個完整、可單獨描述的改變（A 否），它是「開口問」的前段 → 併進下一鏡開頭當 A 段。判定合併，不是刪【盲測：六個獨立評審同一結論】。
2. **重複與更簡形式（跨事件）**：一段對照用的情侶戲，有三鏡都在說「他們的親密是習慣」：順手撥頭髮、靠在一起滑手機、玩鬧推擠。後兩鏡更強，撥頭髮又是小尺度動作 → 不必獨立成鏡；它的敘事功能由另外兩鏡吸收，所以是合併，不是刪。撥頭髮可以當鄰鏡的支持線索。第一個出現的例子，不等於自動值得一鏡。因為這一鏡對應另一個核可事件，判定寫問。
3. **停留併進出點**：「肩膀開始抖」之後「無聲地哭」。哭的那一刻能完整留在前一鏡的出點停留 → 合併，不是刪。
4. **尺度跟著表達點**：角色聽到等了很久的消息，停下手上的動作、猛抬頭追問。
   - 表達點是「手停住、猛抬頭」→ BODY，中景讀得到；
   - 表達點是「她的臉亮起來」→ FACE，近景。
   
   同一拍，表達點選得不同，尺度就不同：先定表達點，再定尺度。
5. **定向**：另一條人物線第一次出場、換到新地點，後面的對照都靠它 → 保留，類型是定向。反例：同一客廳、同一晚、同樣坐姿，再放一次全景 → 刪。

劇情安全的兩個例子見 §15，拍誰的例子見 §13。

## 22. 禁止

- 為了電影感加鏡或靠近；把景別變化當成敘事變化。
- 用拍的種類硬對照景別（情緒＝近景、關係＝中景）；把「全中近特全」當預設序列。
- 要求每一鏡都有新事實；或反過來，留下前提不成立的延宕、停留、定向、呼應鏡。
- 讓小物件、小字、精確數量、微表情承擔核心資訊。
- 靜默替換核可的動作、人聲、說話者、在場人物或事件順序；為了好生成偷偷改劇情。
- 把【盲測】的結果寫成 H3 已驗證；讓 Camera DSL 決定敘事；為了理論完整加欄位。
